# PPT 슬라이드 구성안 — ETF 선정·분석기간·추천 파이프라인

> ETF 선정기준, 분석기간 설정 근거, 입력값 기반 추천 과정을 PPT에 담는 슬라이드별 구성 가이드.

---

## 전체 슬라이드 순서

```
1. 시장 배경 (400조, DC 방치 68.4%)
2. 문제 정의 + 우리 솔루션 매핑
3. [슬라이드 A] ETF 유니버스 깔때기
4. [슬라이드 B] 13개 슬롯 구조
5. [슬라이드 C] 5년 분석기간 선정 근거
6. [슬라이드 D] 전체 파이프라인 흐름도  ← 핵심
7. [슬라이드 E] XAI 출력 예시
8. 백테스트 결과 (+84% 수익, MDD -24.4%)
9. 기존 시스템 vs 우리 시스템 비교표
```

슬라이드 A~C는 "데이터 신뢰도" 파트, D~E는 "시스템 작동 원리" 파트.

---

## Part 1 — ETF 선정기준 + 분석기간

### 슬라이드 A: ETF 유니버스 구축 (깔때기)

세로 흐름 다이어그램. 각 단계 옆에 기준 1~2줄 + 통과 숫자 표기.

```
[KRX 전체 상장 ETF]
        ↓
  기초 필터
  · 레버리지·인버스·상장폐지 제거 (추적배수='일반', is_delisted=False)
        ↓
  유동성·비용 필터
  · AUM ≥ 500억 원
  · 일평균 거래대금 ≥ 10억 원 (최근 250거래일)
  · 총보수 ≤ 전체 평균 + 1σ
        ↓ 196개 우량 ETF (filtered_universe.csv)
  13개 자산군 슬롯 분류
        ↓
  연도별 대표 ETF 1개 선정
  · 우선순위: 순수지수 추종 → 비환헤지 → AUM 최대
  · 점수 = 총보수×0.5 + 거래대금×0.3 + AUM×0.2 (최솟값 선택)
        ↓ 71개 (year_end_best.csv, 2015~2024)
```

**강조 포인트**: "생존편향 차단 — 과거 각 시점에 실제 투자 가능했던 ETF만 사용"

---

### 슬라이드 B: 13개 슬롯 구조

테이블 또는 트리맵 형태.

| 자산군 | 슬롯 |
|--------|------|
| **국내주식** | 국내주식_코스피 / 국내주식_코스닥 |
| **미국주식** | 미국주식_SP500 / 미국주식_나스닥 |
| **신흥국** | 신흥국_인도 / 신흥국_중국 |
| **국내채권** | 국고채단중기 / 국고채장기 / 회사채 / 종합 |
| **해외채권** | 미국국채 (비환헤지 초단기) |
| **원자재** | 금 |
| **무위험자산** | 현금성 (KODEX 머니마켓액티브) |

**핵심 한 줄**: "슬롯 = 포트폴리오의 자리. 매년 그 자리에 들어갈 최적 ETF가 바뀜."

---

### 슬라이드 C: 5년 분석기간 선정 근거

4개 기준 비교 테이블 + 결론 박스.

| 기준 | 1년 | 2년 | 3년 | **5년 ★** |
|------|-----|-----|-----|-----------|
| 평균 예측오차(%) | 2.67 | 2.94 | 2.87 | 2.85 |
| 소르티노 비율 | 0.572 | 0.561 | 0.512 | **0.600** |
| 일관성 (소르티노 σ) | 1.652 | 1.691 | 1.582 | **1.591** |
| 이상치 민감도 | 0.073 | 0.009 | 0.015 | **0.015** |
| **종합 점수** | 0.644 | 0.267 | 0.428 | **0.728** |

> **결론**: 1년은 COVID·금리충격에 과도하게 반응. **5년이 성과와 안정성 모두 최고.**

**MAR 설명 한 줄**: "기준 수익률(MAR) = ECOS 정기예금 금리 — 매 분기 자동 갱신하여 무위험 대안보다 못한 구간만 진짜 손실로 측정."

## Part 2 — 입력값에 따른 추천 과정

### 슬라이드 D: 전체 파이프라인 흐름도 (핵심 슬라이드)

레인(Lane) 다이어그램 또는 세로 흐름도 권장.

```
┌─────────────────────────────────────────────┐
│  NVIDIA 팀 페르소나 시스템                    │
│  텍스트 입력 → Embedding → Ridge → PCA 변환  │
└────────────────────┬────────────────────────┘
                     ↓
┌─────────────────────────────────────────────┐
│  Risk Score 산출 (1~10)                      │
│                                              │
│  자금역량 (Part 1) ×0.30                     │
│  · investable_capital, years_worked          │
│  · years_to_retire, income_dependency        │
│                                              │
│  기여안정성 (Part 2) ×0.30                   │
│  · job_type, expected_contribution           │
│  · income_level                              │
│                                              │
│  시간지평 점수 ×0.30                          │
│  직업안정성 + 가족상황 ×0.25 / ×0.15          │
└────────────────────┬────────────────────────┘
                     ↓
┌─────────────────────────────────────────────┐
│  위험군 분류 → 위험자산 비중(w_risky) 결정    │
│                                              │
│  1~2점: 초보수형  →  0%                      │
│  3~4점: 보수형    →  20%                     │
│  5~6점: 중립형    →  40%                     │
│  7~8점: 성장형    →  60%                     │
│  9~10점: 공격형   →  70%  (법적 상한)         │
└────────────────────┬────────────────────────┘
                     ↓
┌─────────────────────────────────────────────┐
│  포트폴리오 산출                              │
│                                              │
│  w_risky  × Sortino-max ETF 포트폴리오        │
│  (1-w_risky) × 무위험자산 ETF                │
│                                              │
│  제약: US≤50%, KR≤50%, EM≤15%               │
│        개별 슬롯 1~40%, 위험자산 ≤70%         │
└────────────────────┬────────────────────────┘
                     ↓
┌─────────────────────────────────────────────┐
│  XAI 설명 생성                               │
│                                              │
│  Layer A (사용자 대면)                        │
│  · a1: Risk Score → w_risky 경로             │
│  · a2: 하위변수 기여 워터폴                   │
│  · a4: 손실 금액 기준 위험 제시               │
│  · a0: 기회비용 금액화                        │
│                                              │
│  Layer B (심화 분석)                          │
│  · b1: 자산별 하방위험 기여(MCDR)             │
│  · b3: 제약 활성화 비용                       │
└─────────────────────────────────────────────┘
```

### 슬라이드 E: XAI 출력 예시 (실제 숫자로)

Risk Score 6점 입력 예시 사용.

| 항목 | 값 |
|------|-----|
| Risk Score | **6점** → 중립형 |
| w_risky | **40%** |
| 포트폴리오 | ETF 비중 파이 차트 |
| 손실 기준 위험 | "최악 분기 -OO만원" |
| 기회비용 | "원리금보장형 10년 방치 시 약 OOO만원 손해" |

- 왼쪽: Layer A 워터폴 차트 (각 변수 → Risk Score 기여)
- 오른쪽: 포트폴리오 파이 차트 (ETF별 비중)
- 하단 강조 박스: 기회비용 금액
