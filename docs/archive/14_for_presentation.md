## 2. 방치의 원인 → 우리 솔루션 매핑

단순한 무관심이 아닌 **구조적 원인**이 있으며, 우리 시스템은 각 원인에 직접 대응한다.

| 방치의 구조적 원인 | 기존 방식의 한계 | **우리 시스템의 대응** |
|-----------------|--------------|---------------------|
| **(a) 선택 마비** — 수십~수백 개 상품, 판단 기준 없음 | 상품 목록 나열 | **XAI Layer A** — "왜 이 포트폴리오인가" 근거를 단계별로 제시 |
| **(b) 개인화 부재** — 나이·위험등급 외 본인 상황 미반영 | 5~10문항 성향 설문, TDF는 나이만 반영 | **Risk Score** — 자금역량(Part1) + 기여안정성(Part2) + 가족 + 시간지평 + 텍스트 성향 |
| **(c) 손실회피·현상유지 편향** — 원금 손실 공포 | 수익률(%)로 제시 → 비교 기준 없음 | **기회비용 금액화** — "10년 방치 시 X만원 손해"로 방치의 비용을 가시화 |
| **(d) 금융이해도 격차** — 자산배분·리밸런싱 개념 모름 | 전문 용어 그대로 출력 | **XAI Layer A** — 금액 기준 손실 제시, 자연어 설명으로 접근 장벽 낮춤 |
| **(e) 퇴직연금 특수성** — "원금은 절대 안 된다" 심리 | 일반 투자 로직 그대로 적용 | **Σ_down 기반 Sortino 최적화** + **DC/IRP 70% 법적 상한 내재화** |

| **자금 역량 반영** | 현재 자산 규모만 | `investable_capital`, `years_worked`, `years_to_retire`, `income_dependency` | 지금 얼마 있느냐보다 "앞으로 얼마나 쌓을 수 있느냐"가 위험 감내력을 결정 |

| **법적 제약 내재화** | 없음 | w_risky ≤ 70% (DC/IRP 위험자산 법적 상한) | 한국 자본시장법상 퇴직연금 위험자산 70% 상한 — 시스템이 자동으로 준수 |
| **지역 집중 리스크** | 자유 최적화 | US≤50%, KR≤50%, EM≤15% | 단일 시장 쏠림 방지, 중국 테일리스크 반영 — 제약 없으면 백테스트에서 미국 100% 수렴 |
| **설명 가능성** | 결과만 제시 (블랙박스) | XAI Layer A (개인화 경로) + Layer B (포트폴리오 분석) | "왜 이 포트폴리오인가"를 레이어별로 공개 — 투자 자문이 아닌 근거 제시 포지셔닝의 핵심 |
| **기회비용 표현** | % 수익률 | 원리금보장형 100% 방치 대비 금액(만원) 차이 | 추상적 수익률보다 "10년 방치 시 X만원 손해"가 투자자에게 실질적으로 와닿음 |

## 기술 차별화 심층 설명

### 하방공분산 (Σ_down) — 왜 표준편차 대신인가

**문제**: 일반 분산·표준편차는 상방 변동과 하방 변동을 동등하게 "위험"으로 처리한다.
퇴직연금 가입자에게 수익이 예상보다 높은 것은 위험이 아니다. 손실만 위험이다.

**우리 선택**:
```
Σ_down = D.T @ D / T
D[t,i] = min(r[t,i] - MAR, 0)   ← 손실(하방 이탈)만 포착
```
- MAR(최소수용수익률)은 ECOS 정기예금 금리를 분기마다 갱신 → 무위험 대안보다 못한 수익만 진짜 손실
- BL 내재수익률도 Σ_down 기반으로 산출 → 하방위험 관점이 시스템 전체에 일관되게 적용됨

**직관적 발표 멘트**:
> "퇴직연금에서 손실은 복구할 시간이 없습니다. 
> 표준편차는 '잘 됐을 때'도 위험이라고 부르지만, 
> 우리는 **예금 금리보다 못한 구간만** 위험으로 측정합니다."

**근거**: Estrada (2007) — 정규분포 가정 없이 하방위험만 포착하는 측도

---

### 블랙-리터만 모델 — 왜 과거 수익률 평균 대신인가

**문제**: 마코위츠 최적화에 과거 수익률 평균을 그대로 넣으면 추정 오류가 증폭된다.
과거에 잘 됐던 자산이 미래에도 높은 비중으로 쏠리는 "오류 최대화기(error maximizer)" 현상이 발생한다.

**우리 선택**:
```
Π = λ × Σ_down × w_mkt   ← 시장 포트폴리오에서 기대수익률 역산
λ = 3.0                   ← 표준값 2.5 + 퇴직연금 보수성 반영 상향
                           (Merton(1969) 장기투자자 λ 범위 2~4 중 상단)
```
- 시장 포트폴리오 w_mkt는 모든 투자자의 합의 결과 → 추가 추정 필요 없음
- 과거 수익률 평균을 쓰지 않으므로 추정 오류가 최적화기에 들어가지 않음

**직관적 발표 멘트**:
> "과거 수익률 평균을 쓰면 최적화기가 오류를 증폭시킵니다.
> 우리는 **'시장 전체가 지금 이 비중을 들고 있다면, 암묵적으로 가정하는 수익률은 얼마인가'** 를 역산합니다.
> 시장 균형에서 출발하기 때문에 극단적 쏠림이 사전에 억제됩니다."

**λ=3.0 선택 근거 한 줄**:
> "표준값 2.5보다 높은 3.0을 택한 이유 — 퇴직연금은 손실 복구 기회가 없는 장기 자금이기 때문입니다."

### XAI — 왜 블랙박스가 아닌가

**문제**: 기존 로보어드바이저는 결과(비중)만 제시한다. 가입자는 왜 이 배분인지 알 수 없고, 신뢰하기 어렵다.
또한 법적으로 "투자 추천"이 되지 않으려면 **근거를 공개하는 것**이 포지셔닝의 핵심이다.

**우리 선택 — 2개 레이어**:

| 레이어 | 대상 | 내용 |
|-------|------|------|
| **Layer A** (사용자 대면) | 가입자 | a1: Risk Score → w_risky 경로 / a2: 하위변수 기여 워터폴 / a4: 손실 금액 기준 위험 제시 / a5: 내재 λ (시장 평균 대비 내 위치) / a6: MVP vs Sortino 비교 / a0: 기회비용 |
| **Layer B** (분석용) | 심화 열람자 | b1: MCDR 자산별 하방위험 기여 / b2: BL 산포도 / b3: 제약 활성화 비용 / b4: 성과 기여 분해 |

**핵심 포지셔닝**:
> "이 시스템은 투자 일임·자문이 아닌, 데이터 기반 **투자 참고 정보**를 제공합니다.
> 의사결정권은 전적으로 투자자에게 있으며, **XAI를 통해 분석 근거를 투명하게 공개**합니다."

XAI가 이 포지셔닝을 가능하게 한다 — "추천"이 아닌 "근거 제시"이기 때문에 규제 위반 소지가 없다.

**직관적 발표 멘트**:
> "포트폴리오를 받았을 때 '왜 이 비중인가요?'라고 물으면 대답할 수 있는 시스템을 만들었습니다.
> Layer A는 **내가 왜 이 위험군에 속하는지**, Layer B는 **이 포트폴리오가 왜 효율적인지** 를 설명합니다."

## 요소별 1줄 발표 멘트

### 1. 자금역량 + 기여안정성 (Part 1 / Part 2)
> "설문 '당신은 공격적입니까?'보다 **지금까지 몇 년 일했고, 앞으로 몇 년 남았으며, 매달 기여금이 얼마나 안정적인지**가 실제 위험 감내력을 결정합니다."

### 2. 하방공분산 Σ_down
> "퇴직연금에서 손실은 복구 시간이 없습니다. 그래서 상방·하방 모두 위험으로 보는 표준편차 대신, **하락했을 때만 측정하는 하방공분산**으로 최적화했습니다."

### 3. DC/IRP 70% 법적 상한
> "어떤 Risk Score가 나와도 **위험자산 비중이 70%를 넘지 않습니다**. 자본시장법 제104조를 시스템이 자동 준수합니다."

### 4. XAI
> "결과만 주는 블랙박스가 아닙니다. 'Layer A'는 왜 이 비중이 산출됐는지 개인화 경로를 설명하고, 'Layer B'는 자산별 위험 기여와 제약 비용을 분석합니다. **투자 추천이 아닌 근거 제시**입니다."

### 5. 기회비용 금액화
> "수익률 +4% 같은 숫자보다 **'10년간 원리금보장형에 방치하면 약 X만원을 기회비용으로 잃습니다'** 가 실제 의사결정을 바꿉니다."

## 발표에서 쓸 수 있는 대비 구도

```
기존 시스템                     우리 시스템
─────────────────────────────────────────────
설문 5문항                  →  자금역량 + 기여안정성 + 텍스트 성향
표준편차 최소화              →  하방공분산 Sortino 최대화
과거 수익률 평균             →  BL 내재수익률 (시장 균형 역산)
결과만 제시                 →  XAI Layer A/B (근거 투명 공개)
% 수익률                   →  금액(만원) 기회비용
법적 제약 무시              →  DC/IRP 70% 상한 자동 준수
```
