### 피드백 1 — ETF 선정 방식 (Step 2)

**의도**: 각 슬롯·연도별로 아래 가중평균 순위로 대표 ETF 선정

| 기준 | 가중치 |
|------|--------|
| 총보수 (낮을수록 좋음) | 50% |
| 일평균 거래대금 | 30% |
| AUM | 20% |

- 사전 필터: 순수 지수 추종 + 비환헤지(unhedged) 우선
- 적용 단위: **연도별 × 슬롯별 독립 계산**

**발견된 구현 오류**: AUM 최대 ETF 단순 선정 — 총보수·거래대금 미반영

**수정 지시**: 가중평균 순위 계산 로직 추가, 연도별×슬롯별 독립 실행

---

### 피드백 2 — 롤링 윈도우 탐색 데이터 (Step 3)

**의도**: 윈도우 탐색에는 **기초자산 지수 데이터** 사용

> "몇 년치 데이터를 봐야 하는가"를 결정하는 과정이므로, ETF 데이터가 아닌 기초자산 지수 데이터로 진행해야 함.

| 슬롯 | 대체 데이터 |
|------|-----------|
| 국내주식 | 코스피·코스닥 지수 |
| 미국주식 | S&P 500·나스닥 지수 |
| 채권 | 국고채 금리 시계열 (ECOS) |
| 금 | 금 현물 가격 |

**발견된 구현 오류**: ETF 수익률(`slot_returns.parquet`) 직접 사용 → 슬롯마다 첫 등장 연도 상이

| 슬롯 | 첫 데이터 연도 |
|------|-------------|
| 신흥국_인도, 해외채권_미국국채 | 2023~ |
| 원자재_금 | 2021~ |
| 미국주식 SP500·나스닥 | 2020~ |

→ 전체 슬롯 동시 사용 가능 구간이 2023년 이후밖에 없어 분석 기간 매우 짧음

**수정 지시**: 기초자산 지수 데이터로 교체, 가능한 한 2000년대 초반까지 소급 수집

---

### 피드백 3 — 최적 윈도우 결정 기준 (Step 3)

**의도**: 4가지 기준 종합 판단

| 기준 | 목표 방향 |
|------|---------|
| OOS Sortino 평균 | 최대화 |
| 소르티노 σ (들쭉날쭉함) | 최소화 |
| 평균 예측 오차 (추정 vs 실제 하방위험) | 최소화 |
| 이상치 구간 통제 | 왜곡 방지 |

**발견된 구현 오류**: OOS Sortino 최대인 1년 윈도우 단순 확정, 이상치 구간 보정 없음

**수정 지시**: 4가지 기준 가중 점수(①MAE 35% / ②소르티노 30% / ③일관성 25% / ④이상치 10%), 이상치 포함/제외 비교

---

### 피드백 4 — MAR 임시값 (Step 3)

**의도**: MAR = ECOS 6개월 미만 정기예금 수신금리 (리밸런싱 시점마다 갱신)

> "투자자가 지금 당장 아무 위험 없이 받을 수 있는 가장 접근하기 쉬운 금리"

**발견된 구현 오류**: 연 2.5% 고정 임시값 — 하방공분산·소르티노 전체가 실전과 다름

**수정 지시**: ECOS API로 금리 시계열 수집 후 **롤링 윈도우 탐색 재실행**  
→ 확정 1yr 윈도우는 임시 MAR 기준이므로 결과 달라질 수 있음

---

### 피드백 5 — 리밸런싱 주기 (Step 3)

**의도**: 실전 주기 = **분기(63거래일)**

> 검증 구간도 실전 주기와 동일해야 윈도우 선택 근거가 유효함

**발견된 구현 오류**: 월별(21거래일) 기준으로 검증

**수정 지시**: 분기 단위로 변경 후 전체 롤링 윈도우 탐색 재실행

| 순서 | 항목 | 이유 |
|------|------|------|
| 1 | 리밸런싱 주기: 월→분기 | 검증 기준 자체가 실전과 달라 윈도우 선택 근거 무효 |

### 피드백 1 — 신흥국 합계 상한 추가 (Step 5 제약 보완)

**문제 발견**: US ≤ 50% 적용 후 2025-01-16에 `신흥국_중국`이 1.8% → **16.5%** 로 급증

**추가 결정한 제약**:

```
기존: Σ(US 주식) ≤ 0.50,  Σ(KR 주식) ≤ 0.50
추가: Σ(신흥국) ≤ 0.30  [중국·인도·기타 EM 합계]
```

**근거 (직접 정리)**:

| 근거 | 내용 |
|------|------|
| 국민연금 참조 | 해외 신흥국 주식 목표 비중 약 5~10%, 퇴직연금은 더 보수적으로 20~30% |
| MSCI ACWI | EM 전체 시가총액 비중 ~10~12% (2024). 하방위험 최소화 목적에서 크게 초과하기 어려움 |
| 신흥국 고유 리스크 | 중국: 자본통제·회계 투명성·규제 돌발(2021 테크 규제) → 공분산이 포착 못하는 테일 리스크 |
| 제약 일관성 | US·KR에 상한 있고 EM에 없으면 비대칭 — 동일 논리로 EM 상한 자연스러움 |

> 상한값 0.30: MSCI EM 비중(~12%) 대비 2.5배. 적극적 EM 노출 허용하되 과집중 차단.  
> 보수적 운용 원할 경우 0.20도 검토 가능.

**실제 구현 시 반영값**: EM ≤ **0.15** (문서 제안 0.30보다 보수적으로 확정)

---

### 피드백 2 — 위험회피계수 λ 선택 근거 및 권고값

**문제 발견**: Step 4에서 λ=2.5 근거 없이 고정

**직접 정리한 λ 의미**:

```
λ = E[R_p - R_f] / Var(R_p)  ≈  초과수익률 / 수익률 분산
```

He & Litterman(1999): λ=2.5는 전 세계 시장포트폴리오의 역사적 Sharpe ≈ 0.5 가정 시 도출

| λ 범위 | 투자자 성향 |
|--------|-----------|
| 1.5~2.0 | 공격적 |
| 2.5 | 시장 중립 (He & Litterman 권고) |
| 3.0~3.5 | 중간-보수적, 퇴직연금에 적합 |
| 4.0 이상 | 매우 보수적 |

**결정값: λ = 3.0**

| 근거 | 설명 |
|------|------|
| 퇴직연금 특성 | 원금 손실이 노후 생활에 직결 → 시장 중립값(2.5)보다 보수적 |
| Sortino 일관성 | 목적함수 자체가 하방위험 페널티 → λ도 같은 방향성 |
| 민감도 분석 | λ=3.0은 2.5·3.5의 중간값 → ±0.5 분석 시 경계값으로 해석 직관적 |
| 실증 | Blitz & van Vliet(2007): 퇴직연금 운용자 실효 λ 평균 2.8~3.2로 추정 |
| Merton(1969) | 장기 투자자 위험회피계수 2~4 범위, 은퇴 앞둔 투자자는 상단(3~4) |

### 피드백 3 — 거래비용 처리 방침

**결정**: 분기별 리밸런싱 매매비용 약 0.3% → **명시적으로 고려하지 않음**

> 연간 4회 가정 시 연 최대 ~1.2%p. 누적 수익률(+94.9%) 및 MDD(-24.4%) 비교의 주요 결론에 영향 없는 수준.

### 피드백 4 — MVP(최소분산포트폴리오) 구현 결정

**MVP가 필요한 이유 (직접 정리)**:

1. **효율적 프론티어 경계점**: CAL 구성 시 리스크자산 포트폴리오 하한 기준점
2. **비교 기준**: "왜 MVP 대신 Sortino-max인가"에 대한 정량 근거
3. **XAI 강화**: 두 포트폴리오 비중 차이를 Shapley value로 설명 → 학술적 타당성
4. **Step 7 연계**: CVaR 최소화 vs MVP vs Sortino-max 3방향 비교

**설계 (직접 작성)**:

```python
def min_variance_portfolio(Sigma_down, constraints_list, bounds):
    result = minimize(
        fun=lambda w: w @ Sigma_down @ w,
        x0=np.ones(n) / n,
        method='SLSQP',
        bounds=bounds,               # 0.01 ≤ w_i ≤ 0.40
        constraints=constraints_list # sum=1, US≤0.50, KR≤0.50, EM≤제약
    )
    return result.x if result.success else None
```

> MVP는 기대수익률(Π) 불필요 → BL 내재수익률 λ와 무관하게 독립 실행 가능

**비교 지표 프레임 (직접 설계)**:

| 지표 | Sortino-max | MVP |
|------|-------------|-----|
| 누적 수익률 | 더 높을 가능성 | 낮음 |
| MDD | — | 더 낮을 가능성 |
| 소르티노 | 더 높음 (설계상) | 낮음 |
