## 1. 투자 성향 유형 분류 (5가지)

KCGI자산운용 기준 및 엔비디아 데이터 페르소나 매핑:

| 유형 | 특성 | 엔비디아 데이터 필터 | 투자 행태 |
|------|------|-----------------|---------|
| **안정형** | 원금 손실 극도 회피, 비투자형 | 교사, '신중한'/'보수적인' | 원리금보장형 100% 방치 |
| **안정추구형** | 간접투자형, 장기 성향 | 연구원, '계획적인'/'성실한' | 예금 70% + 우량 ETF 30% |
| **위험중립형** | 균형 투자, 확신 부족 | 대기업 사무직, '실용적인' | TDF + 지수 ETF 5:5 |
| **적극투자형** | 병행투자형, 기회 시 레버리지 | 마케터, '사교적인'/'능동적인' | 테마 ETF 비중 높음 |
| **공격투자형** | 직접투자형, 변동성 선호 | SW엔지니어, '분석적인'/'모험가' | 퇴직연금 100% 공격적 ETF |

## 2. Risk Score 최종 산정식

```
Risk Score (1~10점) =
  0.20 × 은퇴기간 점수
+ 0.15 × 나이 점수
+ 0.15 × 직업 점수
+ 0.20 × 자금여력 점수
+ 0.15 × 가족 점수
+ 0.15 × 라이프스타일 점수
```

### 2-A. 나이 점수

| 나이 구간 | 인적자본 상태 | 점수 |
|---------|------------|------|
| 20대 (20~29세) | 최대 (인적자본 > 금융자산) | **10점** |
| 30대 (30~39세) | 높음 (소득 성장기) | **8점** |
| 40대 (40~49세) | 중간 (유동성 수요 증가) | **6점** |
| 50대 (50~59세) | 감소 (은퇴 준비 전환기) | **4점** |
| 60세 이상 | 최소 (인출 단계 진입) | **2점** |

이론 근거: Modigliani(1954) 생애주기 가설, Rule of 110

### 2-B. 은퇴까지의 기간 점수

| 은퇴까지 기간 | TDF 단계 | 점수 |
|------------|---------|------|
| 30년 이상 | 초기 축적기 | **10점** |
| 20~30년 | 성장기 | **8점** |
| 10~20년 | 보수화 전환기 | **6점** |
| 5~10년 | 보전 강화기 | **3점** |
| 5년 미만 | 인출 준비기 | **1점** |

이론 근거: Bodie, Merton & Samuelson(1992) Time Horizon Risk Capacity; OECD(2021) 퇴직연금 가이드라인

**두 시간 변수 내부 상대 가중치**: 나이 40% : 은퇴기간 60%
(은퇴기간이 실제 투자 가능 기간의 직접 측정값으로 더 높은 변별력)

### 2-C. 직업 안정성 점수

| 직업 유형 | 점수 |
|---------|------|
| 공무원, 공기업, 교사, 정규직 전문직 | 9~10 |
| 대기업/중견기업 정규직 | 7~8 |
| 일반 사무직/서비스직 정규직 | 5~7 |
| 자영업, 프리랜서, 계약직 | 3~5 |
| 무직, 소득 불안정 | 1~3 |

※ 직업 안정성은 특정 직업의 우열 판단이 아닌, 퇴직연금 기여금이 안정적으로 유입될 가능성 추정을 위한 보조 변수

### 2-D. 자금여력 점수

```
자금여력 점수 = Part1(손실감내도) × 0.40
             + Part2(기여안정성) × 0.35
             + Part3(리밸런싱여력) × 0.25

Part 3 핵심: 위험자산 추가 여력 = 70% - 현재 위험자산 비중
```

### 2-E. 가족 점수

부양 책임이 커질수록 감소 (배우자·자녀 수, 부양가족 여부 반영)

### 2-F. 라이프스타일 점수 (텍스트 기반)

엔비디아 페르소나 텍스트 → Big Five 3축 점수화:

```python
risk_score_lifestyle = (
    0.45 * openness_z
  - 0.45 * stability_preference_z
  + 0.10 * conscientiousness_z
)
→ qcut → 1~5등급
```

| 축 | 의미 | Risk Score 영향 |
|----|------|---------------|
| openness (개방성) | 새로운 경험, 도전, 변화 수용 | 높을수록 상승 |
| conscientiousness (성실성) | 계획성, 장기 전략 유지 | 높을수록 소폭 상승 |
| stability_preference (안정선호) | 손실 회피, 안정 추구 | 높을수록 하락 |

## 3. 위험군 분류 → w_risky 조회

| Risk Score | 위험군 | w_risky | 설명 |
|------------|--------|---------|------|
| 1~2점 | 초보수형 | **0%** | 전액 무위험자산 |
| 3~4점 | 보수형 | **20%** | |
| 5~6점 | 중립형 | **40%** | |
| 7~8점 | 성장형 | **60%** | |
| 9~10점 | 공격형 | **70%** | DC/IRP 법적 상한 |

## 4. 최종 배분 계산

```
최종 포트폴리오 = w_risky × Sortino-max 포트폴리오
               + (1 - w_risky) × 무위험자산(현금성 ETF)
```

## 5. 같은 Risk Score 문제 — 2단계 개인화

같은 Risk Score라도 **하위 점수 구성이 다르면 최종 배분을 다르게** 조정한다.

```
1단계: Risk Score → 위험군(그룹) → w_risky 기본 비중
2단계: 하위 점수 프로필 → w_risky 내 세부 조정
       예) 은퇴기간 짧음 → 주식 비중 축소
           자금여력 낮음 → 현금성 확대
           가족부담 높음 → 고변동 ETF 축소
```

XAI 활용: "두 사용자의 Risk Score는 7.5점으로 같지만, A는 긴 투자기간이 점수를 높였고 자금여력이 낮춰서 현금성 비중을 높였습니다."

## 6. 텍스트 처리 파이프라인 (07번 문서 기준)

```
원문 텍스트 10만 개 (엔비디아 페르소나 라이프스타일 컬럼)
  ↓
1. 문장 embedding: ko-sroberta-multitask (768차원)
  ↓
2. KMeans 클러스터링 (500개 군집)
  ↓
3. 클러스터 대표 문장 추출 (코사인 유사도 기준 중심 문장)
  ↓
4. 대표 문장 500개만 GPT 점수화
   → openness, conscientiousness, stability_preference (각 1~5점)
  ↓
5. 클러스터 점수를 전체 10만 행에 전파
  ↓
6. 원점수 분포 확인 (구분력 검증)
  ↓
7. z-score 표준화
  ↓
8. persona 규칙 적용 (z-score 기준)
  ↓
9. risk_score = 0.45×openness_z - 0.45×stability_z + 0.10×conscientiousness_z
  ↓
10. qcut → 라이프스타일 점수 1~5등급
```

### GPT 점수화 프롬프트 핵심 기준

- openness 1점: 변화 회피, 익숙한 삶 선호 / 5점: 창업·혁신·비정형 삶 강하게 추구
- conscientiousness 1점: 무계획적, 충동적 / 5점: 강한 완벽주의, 장기 전략, 높은 자기통제
- stability_preference 1점: 위험 감수 성향 강함 / 5점: 손실·불안정에 매우 민감 (5점 매우 드물게)

### persona 규칙 예시

```python
def assign_persona(row):
    if row["openness_z"] >= 0.7 and row["stability_preference_z"] <= -0.3:
        return "성장도전형"
    elif row["stability_preference_z"] >= 0.5 and row["openness_z"] <= -0.3:
        return "안정유지형"
    elif row["openness_z"] >= 0.3 and row["conscientiousness_z"] >= 0.3:
        return "성장관리형"
    elif row["conscientiousness_z"] >= 0.5 and row["stability_preference_z"] >= 0.3:
        return "책임안정형"
    else:
        return "균형형"
```

## 7. 엔비디아 데이터 역할

엔비디아 페르소나 데이터는 **예측 모델 학습용이 아닌** 기반 데이터로 활용:

| 엔비디아 데이터 컬럼 | 활용 방식 |
|----------------|---------|
| 나이 | 나이 점수 직접 산정 |
| 배우자·가족 여부 | 가족부담 점수 산정 |
| 직업 | 직업 안정성 점수 추정 |
| 라이프스타일 텍스트 | Big Five z-score → 라이프스타일 점수 |

전체 Risk Score 중:
- 엔비디아 데이터 기반: 약 60% (나이+직업+가족+라이프스타일)
- 사용자 추가 입력: 약 40% (은퇴기간+자금여력)

## 8. 리밸런싱 서비스 구조

### 최초 포트폴리오 추천

```
개인 조건 입력 (나이, 가족, 직업, 자산, 은퇴 목표)
→ Risk Score 계산
→ 위험군 분류 → w_risky
→ 최초 목표 포트폴리오 산출
→ XAI 기반 근거 설명 + 기회비용 계산
```

### 리밸런싱 (분기 주기)

```
기존 개인 조건 불러오기
→ 현재 포트폴리오 평가금액 입력
→ 개인 조건 변경 여부 확인
→ 최신 시장 데이터 자동 업데이트
→ 새 목표 포트폴리오 재계산
→ 현재 vs 목표 비중 비교
→ 리밸런싱 판단 기준:
   ±5%p 이내 → 유지, ±5%p 초과 → 권고, ±10%p 초과 → 적극 권고
→ 조정 필요 금액 + XAI 설명
```
