## Part A. ETF 시계열 데이터 수집

### A-1. 개요

| 항목 | 내용 |
|------|------|
| 수집 기간 | 2020.01.01 ~ 2025.04.30 |
| 핵심 원칙 | 생존편향(Survivorship Bias) 제거 — 상장폐지 종목 포함 |
| 최종 목표 | 퇴직연금 적격 ETF 일별 OHLCV 단일 데이터셋 |

### A-2. 마스터 유니버스 구축

**현재 상장 ETF (KRX)**

- 경로: data.krx.co.kr → 통계 → 증권상품 → ETF → 전종목 기본정보 → CSV 다운로드
- 수집 항목: 단축코드, 한글종목명, 상장일, 추적배수, 복제방법, 기초자산분류

**상장폐지 ETF (KIND)**

- 경로: kind.krx.co.kr → 상세검색 (시장구분: ETF, 기간: 2020~2025, 보고서명: 상장폐지)
- ETN 종목은 종목명 기준 필터링하여 제거

**병합**: 단축코드 기준 Outer Join, 현재 상장 우선 적용  
**예상 규모**: 현재 상장 ~900종 + 폐지 ~300~500종 = 총 1,200~1,400종

### A-3. 투자 불능 종목 필터링

| 필터 | 기준 | 사유 |
|------|------|------|
| 레버리지·인버스 | 추적배수 ≠ 1, 종목명에 `레버리지/인버스/2X/곱버스` | 퇴직연금 감독규정 |
| 합성형 파생상품 | 복제방법=합성 + 기초자산 파생형 | 파생상품 40% 초과 불가 |
| 원자재 선물 | 종목명에 `선물` + 농산물·원유·천연가스·금속 기초 | 고위험 파생상품 제한 |

**필터링 후 잔존 규모**: 약 700~900종

### A-4. 수집 절차 (pykrx)

```python
수집_완료_목록 = 이미_수집된_종목_로드()

for 종목코드 in master_filtered['단축코드']:
    if 종목코드 in 수집_완료_목록:
        continue

    try:
        df = pykrx.get_market_ohlcv_by_date('20200101', '20250430', 종목코드)
        결과_저장(df)
    except:
        실패_목록에_기록(종목코드)

    time.sleep(1)   # KRX IP 차단 방지
```

**실무 주의사항**:
- 요청 간격 최소 0.5~1초 (IP 차단 방지)
- 예상 소요: ~800종 × 1초 = 약 13~15시간 → 야간 실행 권장
- 연도별 분리 수집 후 합치기 권장 (한 번에 5년치 요청 시 실패 확률 높음)
- 중단 시 이어서 재개 가능하도록 수집 완료 목록 유지

### A-5. 결측치 처리 규칙

| 구간 | 처리 방법 |
|------|----------|
| 상장 전·폐지 후 | NaN 유지 (매매 불가 구간) |
| 일시적 거래 정지 (≤4일) | ffill (직전 종가 이월) |
| 연속 결측 5영업일 이상 | NaN 유지, 별도 검토 |
| 거래량 = 0 | 유지 (공식 거래 정지일 가능) |
| 종가 = 0 | NaN (데이터 오류) |

## Part B. 거시지표 수집 설계

### B-1. 거시지표 역할 정의

거시지표는 포트폴리오 최적화의 **직접 입력값이 아닌** 두 역할로 한정:

| 역할 | 설명 | 예시 |
|------|------|------|
| 레짐 식별 | 경제 국면 분류 → 기대수익률·공분산 추정에 반영 | 긴축 → 채권 ETF 변동성 확대 반영 |
| 수익률 예측 보조 | 팩터 수익률 또는 ETF 수익률의 조건부 기대값 추정 | 금리 상승 → 단기채 기대수익 하락 조정 |

> 퇴직연금 특성: 장기 관점(≥1년) 우선. 단기 시장 타이밍 사용 지양.

### B-2. 지표 선택 4대 원칙

| 원칙 | 내용 |
|------|------|
| 경제적 유의성 | APT·ICAPM 이론 연결고리 있는 지표만 채택 |
| 선행성 우선 | 동행·후행보다 선행 지표 우선 |
| 고빈도 수집 | 월별 이상 빈도 필수 (분기 발표 지표는 보간 처리) |
| 비중복성 | VIF > 10 지표 제거 또는 PCA 합성 대체 |

### B-3. 다중공선성 처리 전략

```
Step 1: 스프레드 변환
  기간 스프레드 = 국고채10년 - 국고채3년
  신용 스프레드 = 회사채AA- - 국고채3년
  실질금리     = 국고채3년  - CPI(YoY)

Step 2: VIF 필터링 (VIF > 10 제거)

Step 3: PCA 압축 — 금리 계열 직교 팩터로 압축
  PC1 ≈ 금리 레벨 팩터
  PC2 ≈ 기간구조 팩터 (수익률 곡선 기울기)
  PC3 ≈ 곡률 팩터

Step 4: 정상성 확보
  금리: 레벨값 사용 (% 단위, 경제적 의미 보존)
  통화량: 전년동월비 증가율 (로그 차분)
  환율: 전월비 변화율 (로그 차분)
```

| 처리 단계 | 지표 수 | 최대 VIF |
|-----------|---------|---------|
| 처리 전 | 15개 | ~50 |
| 스프레드 변환 후 | 12개 | ~20 |
| VIF 필터링 후 | 9개 | ~12 |
| PCA 압축 후 | 8개 | < 5 |

### B-4. 레짐 분류 모델 (4분면)

```
         물가 상승
              │
    ④ 스태그플레이션 │ ① 과열 (Overheating)
    (금리 상승 필요) │ (긴축 단계, 주식 고점 경계)
──────────────────┼──────────────────── 성장
    경기 침체       │                    강세
    ③ 침체/디플레   │ ② 골디락스
    (완화 기대,     │ (성장+저물가, 주식 강세)
     채권 강세)     │
              │
         물가 하락
```

| 레짐 | 주식 ETF | 채권 ETF | 권장 포지션 |
|------|---------|---------|-----------|
| 골디락스 | ↑ 고수익 | ↔ 중립 | 주식 비중 확대 |
| 과열 | ↔ 변동성 확대 | ↓ 금리 상승 | 단기채·가치주 전환 |
| 침체 | ↓ 급락 | ↑ 안전자산 | 채권·현금 비중 확대 |
| 스태그플레이션 | ↓ | ↓ 양쪽 하락 | 물가연동채·원자재 |

**구현**: HMM(Hidden Markov Model) 기반 소프트 확률 분류 (단일 레짐 할당보다 robust)

### C-3. 파생 지표 산출 명세

| 파생 지표 | 산출식 | VIF 예상 |
|----------|--------|---------|
| 기간 스프레드 | 국고채10년 - 국고채3년 | < 3 |
| 신용 스프레드 | 회사채AA- - 국고채3년 | < 4 |
| 실질금리 | 국고채3년 - CPI(YoY) | < 4 |
| CPI YoY | `CPI_t / CPI_{t-12} - 1` | — |
| M2 증가율 YoY | `log(M2_t) - log(M2_{t-12})` | < 5 |
| M1/M2 비율 | `M1_t / M2_t` | — |
| 전산업생산 YoY | `IPI_t / IPI_{t-12} - 1` | — |
| 원/달러 변화율 | `log(환율_t) - log(환율_{t-1})` | < 5 |

