## 3. 발견된 구조적 문제

### 3-A. BL Π의 수익 예측력 부재 (8-B2)

**현상**: KR주식 2개 슬롯에 대해 Π vs 실현수익률 상관계수 r ≈ -0.26~-0.27 (약한 음의 상관).  
나머지 슬롯(US주식, EM, 채권, 금)은 초기 분기에 추정 윈도우 부족으로 Π 자체가 NaN.

**원인 분석**:
- 현재 모델은 `Π = λ × Σ_down × w_mkt` 만 사용하며, `w_mkt`는 연말 AUM 비중 (정적)
- AUM은 과거 대형주/인기 자산 쏠림을 반영하므로 미래 수익 방향과 무관
- BL 원래 설계(He & Litterman 1999)에서는 Π를 **기준점(prior)**으로 사용하고, **투자자 뷰(Views)**를 얹어 수정된 기대수익률을 산출함
- 현재 구현은 뷰 없이 균형 수익률만 쓰는 **"반쪽 BL"**

**영향**: 최적화 목적함수(Sortino-max)의 기대수익률 신호가 시장 방향성을 전혀 반영하지 못함.

---

### 3-B. 포트폴리오 집중도 문제 (8-B4)

**현상**: 13개 슬롯 사용에도 불구하고 수익의 93%가 국내주식+미국주식에서 발생.

| 자산군 | 누적 기여(%p) | 비율 |
|--------|-------------|------|
| 국내주식 | +27.32 | 47% |
| 미국주식 | +26.56 | 46% |
| 국내채권 | +2.61 | 5% |
| 원자재(금) | +1.09 | 2% |
| 해외채권 | +0.06 | 0% |
| 신흥국 | -0.73 | - |

**원인 분석**:
- Sortino-max는 하방공분산이 낮고 Π가 높은 자산으로 극단적 쏠림 발생
- 채권은 하방공분산이 낮지만 Π도 낮아 비중 한도(W_MAX=40%)까지 채우지 않음
- 분산 효과가 의도한 수준으로 작동하지 않는 구조

**현상**:

**원인 분석**:

- 결과적으로 제약이 오히려 손실 과집중을 막아주는 **우연적 안전장치** 역할을 했지만, 이는 설계 의도가 아님

## 4. 시행착오 기록

### 4-1. Step 7 λ_implied 계산 오류 (수정 완료)

- **v1 오류**: OOS 실현수익률 사용 → 분기 노이즈로 λ 값이 ±수천 단위로 발산
- **v2 오류**: CAL 스케일된 비중(`w_scaled = w_sortino × w_risky`)으로 분산 계산 → 분모에 `w_risky³` 항 포함, λ 값 비정상적으로 큼
- **확정 수식**: `var_risky_q = w_sortino @ Σ_down @ w_sortino × REBAL_DAYS` (100% 리스크자산 기준), `λ = (E[R]_q - MAR_q) / (w_risky × var_risky_q)`

### 4-2. 8-B2 NaN 처리 누락 (수정 완료)

- 초기 구현에서 Π NaN 슬롯을 걸러내지 않아 `np.polyfit` LinAlgError 발생 (`SVD did not converge`)
- 수정: `if np.isnan(pi_val): continue` 추가, `xs.std() > 1e-6` 조건으로 분산 체크, `try/except LinAlgError` 방어 처리

### 4-3. Sortino-max 수익 쏠림

- 초기 기대와 달리 W_MAX=40% 제약에도 불구하고 주식 2개 자산군 집중
- 채권·금을 "분산" 자산으로 편입했지만 기여 극소화 → 구조 재검토 필요

## 5. 개선 방향

### 5-A. 모멘텀 뷰 추가 (우선 진행) ★★★

**목적**: Π에 시장 방향성 신호를 반영해 BL 기대수익률의 예측력 개선.

**방법**: Black-Litterman 뷰 행렬 구성
- 직전 12개월(252거래일) 수익률 기준 슬롯 순위 산출
- 상위 N개 슬롯에 양의 뷰(outperform), 하위 N개에 음의 뷰(underperform) 부여
- 뷰 불확실성 Ω = τ × P × Σ × P' (proportional to prior)
- BL 수정 수익률: `μ_BL = [(τΣ)^{-1} + P'Ω^{-1}P]^{-1} [(τΣ)^{-1}Π + P'Ω^{-1}Q]`

**하이퍼파라미터**: τ (뷰 신뢰도), N (뷰 슬롯 수), 모멘텀 룩백 기간  
**검증**: 8-B2 재실행으로 μ_BL vs 실현수익률 상관 개선 여부 확인

### 5-B. 신흥국 중국 분리 (저비용 개선) ★★★

- EM_CAP을 인도(≤12%)와 중국(≤5%)으로 분리
- 또는 중국을 별도 슬롯으로 제약 강화

### 5-C. λ 동적화 ★★

- VIX 또는 실현변동성 레짐 기반으로 공포 구간(고변동성)에서 λ 상향
- 현재 고정값 λ=3.0 → `λ_t = λ_0 × (σ_t / σ_0)` 형태

### 5-D. 채권 역할 재정의 ★★

- 채권을 "수익 자산"이 아닌 무위험 대체로 취급
- CAL 구성 시 단기 국고채를 무위험 자산으로, 나머지 채권은 별도 슬롯으로 관리

## 7. Step5b 구현 시행착오 및 결과

### 7-1. v1 실패 (2026-05-18)

**시도**: TAU=0.10, ALPHA=0.50 파라미터로 BL 절대뷰 적용.

**결과**: 누적수익률 83.97% → 53.87%로 급락.

**원인 분석 (2가지)**:

① **BL 수식 버그 — τ 소거**  
구현한 수식 `μ_BL = Π + τΣ(τΣ + Ω)^{-1}(Q - Π)` 에서  
Ω = diag(τ × diag(Σ))로 설정하면:  
`τΣ(τΣ + Ω)^{-1} = Σ(Σ + diag(Σ))^{-1}`  
→ τ가 완전 소거됨. TAU 파라미터가 실제로 아무 효과 없었음.  
결과적으로 view 강도가 의도보다 훨씬 강하게 작동 (≈50% 블렌딩).

② **w_mkt AUM 편중**  
초기 분기(2016~2018)에 AUM 데이터가 KR 슬롯만 존재.  
→ Π prior가 KR 과도 집중 → 모멘텀 뷰가 KR 편중을 더 심화.  
KR이 이 기간 US 대비 성과 열위 → 성과 하락.

---

| 항목 | v1 | v2 |

| view 강도 파라미터 | TAU=0.10 (무효) | VIEW_WEIGHT=0.15 (85% prior, 15% view) |

**μ_BL 조정 방향 (뷰가 의도한 대로 작동)**:
- US주식: avg +0.013~+0.019%/분기 → 모멘텀 강세 구간 비중 증가

모멘텀 뷰가 의도한 방향(US 우위, 중국 하향)으로 작동하고 있음.  
성과 개선이 크지 않은 이유: VIEW_WEIGHT=0.15로 보수적 설정,  
그리고 KR 제약 binding 빈도(12/38)가 유지되어 KR 쏠림이 여전함.

## 8. Step5b v3: B+C 적용 결과 (2026-05-18)

### 8-1. 구현 내용

**[B] 음수 모멘텀 슬롯 필터링**
- 12개월 누적 수익률 < 0인 슬롯을 해당 분기 valid_cols에서 제외
- Σ_down, Π 계산 자체가 달라짐 (간접 조정 아닌 직접 제외)
- 무위험(현금성)은 항상 포함, 필터 후 슬롯 수 < 3이면 필터 스킵

**[C] w_mkt 모멘텀 가중**
- `w_mkt = AUM × max(1 + mom_ret, MOM_FLOOR) / Σ`
- 모멘텀 강한 자산 → w_mkt 상승 → Π prior 자체가 높아짐
- 코너 솔루션에서도 효과 발생
- BL view(VIEW_WEIGHT) = 0.0으로 비활성 (B+C로 대체)
