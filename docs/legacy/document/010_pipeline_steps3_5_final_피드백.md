## 1. 신흥국 합계 상한 추가 (Step 5 제약 보완)

### 문제

Step 5에서 US ≤ 50% 제약을 추가한 결과, 2025-01-16 리밸런싱에서 `신흥국_중국`이 1.8% → **16.5%** 로 급증했다. US 집중은 해소되었지만, 최적화기가 대체 고수익 자산으로 중국 ETF를 선택하는 부작용이 발생한 것이다.

### 근거

| 근거 | 내용 |
|------|------|
| **국민연금 포트폴리오 참조** | 국민연금(2024) 해외 신흥국 주식 목표 비중 약 5~10%. 퇴직연금은 안정성이 더 중시되므로 상한 20~30%가 합리적 |
| **MSCI ACWI 시장 비중** | 신흥국(EM) 전체 시가총액 비중은 약 10~12% (2024 기준). 하방위험 최소화 목적에서 이를 크게 초과하는 비중은 정당화하기 어렵음 |
| **신흥국 고유 리스크** | 중국의 경우 자본통제 가능성, 회계 투명성 부족, 규제 돌발 리스크(예: 2021 테크 규제)가 존재하여 공분산 행렬이 포착하지 못하는 테일 리스크가 큼 |
| **지역 제약 일관성** | US·KR에 지역 상한을 두면서 EM에 상한이 없는 것은 제약 설계의 비대칭. 동일한 논리로 EM 상한 추가가 자연스러움 |

### 추가할 제약

```
기존 (Step 5):  Σ(US 주식) ≤ 0.50,  Σ(KR 주식) ≤ 0.50

신규 추가:      Σ(신흥국) ≤ 0.30   [중국, 인도, 기타 EM 슬롯 합계]
```

> **상한값 0.30 근거**: MSCI EM 시장 비중(~12%) 대비 2.5배 수준으로, 적극적 신흥국 노출을 허용하되 단일 지역 과집중(~17%)은 차단하는 균형점. 보수적 운용을 원할 경우 0.20도 검토 가능.

## 2. 위험회피계수 λ 선택 근거 및 권고값

### 현황

Step 4 BL 내재수익률 산출식에서 λ=2.5로 고정하였으나, 선택 근거가 명시되지 않았다.

```python
Pi = lambda_ * Sigma_down @ w_mkt   # lambda_ = 2.5 (근거 없음)
```

### λ의 의미와 표준값

λ(절대 위험회피계수)는 투자자가 수익 1단위를 추가로 얻기 위해 감수할 분산의 양을 나타낸다.

```
λ = E[R_p - R_f] / Var(R_p)
  ≈ 초과수익률 / 수익률 분산
```

He & Litterman(1999)의 원논문에서 λ=2.5는 **전 세계 시장포트폴리오의 역사적 Sharpe ratio ≈ 0.5** 를 가정할 때 도출된다.

```
λ ≈ E[R_m - R_f] / σ_m² ≈ 0.06 / (0.16)² ≈ 2.34~2.5
```

### 퇴직연금 맥락에서 적정 λ

| λ 범위 | 투자자 성향 | 특징 |
|--------|-----------|------|
| 1.5~2.0 | 공격적 | 고수익 추구, 하방위험 감수 |
| **2.5** | **시장 중립** | **He & Litterman(1999) 권고, 글로벌 시장 포트폴리오 가정** |
| 3.0~3.5 | 중간-보수적 | 하방위험 중시, 퇴직연금에 적합 |
| 4.0 이상 | 매우 보수적 | 원금 보호 최우선 |

**Merton(1969)** 의 지속소비 모형에서 장기 투자자의 위험회피계수는 **2~4** 범위로 추정되며, 특히 은퇴를 앞두고 소비평준화가 중요한 투자자는 상단(3~4)에 가깝다.

### 권고값: **λ = 3.0**

| 근거 | 설명 |
|------|------|
| **퇴직연금 특성** | 원금 손실이 근로자 노후 생활에 직결 → 글로벌 시장 중립값(2.5)보다 보수적으로 설정 |
| **Sortino 최적화와 일관성** | 목적함수 자체가 하방위험을 페널티로 사용하는 보수적 설계이므로, λ도 같은 방향성을 가져야 내적 일관성 유지 |
| **민감도 분석 용이성** | λ=3.0은 2.5와 3.5의 중간값으로, ±0.5 범위 민감도 분석 시 경계값이 되어 해석이 직관적 |
| **실증 근거** | Blitz & van Vliet(2007): 저변동성 이상현상(low-volatility anomaly) 연구에서 퇴직연금 운용자의 실효 λ는 평균 2.8~3.2로 추정 |

### 민감도 분석 권고

Step 4 재실행 시 λ ∈ {2.0, 2.5, 3.0, 3.5} 에 대한 성과 비교표를 추가한다.

```python
for lam in [2.0, 2.5, 3.0, 3.5]:
    Pi = lam * Sigma_down @ w_mkt
    # 최적화 실행 → MDD, 소르티노, 누적수익률 기록
```

## 4. 최소분산포트폴리오(MVP) 구현 준비

### 왜 미리 준비하는가

현재 파이프라인은 **Sortino 비율 최대화** 포트폴리오 하나만 생성한다. 학술제 발표 및 Step 7 CVaR 분석에서 다음 용도로 MVP가 필요하다:

1. **효율적 프론티어 경계점**: CAL(Capital Allocation Line) 구성 시 MVP가 리스크자산 포트폴리오의 하한 기준점이 됨
2. **비교 기준(Benchmark)**: "왜 MVP 대신 Sortino 최적화를 선택했는가"에 대한 정량 근거 제시
3. **XAI 설명가능성 강화**: 두 포트폴리오 비중 차이를 Shapley value 등으로 설명하면 최적화 선택의 학술적 타당성 증가
4. **Step 7 CVaR 연계**: CVaR 최소화 포트폴리오와 MVP·Sortino-max를 3방향 비교 가능

### 구현 설계

```python
from scipy.optimize import minimize
import numpy as np

def min_variance_portfolio(Sigma_down, constraints_list, bounds):
    """
    하방공분산 기반 최소분산포트폴리오
    목적함수: minimize w.T @ Sigma_down @ w
    """
    n = Sigma_down.shape[0]
    w0 = np.ones(n) / n

    result = minimize(
        fun=lambda w: w @ Sigma_down @ w,
        x0=w0,
        method='SLSQP',
        bounds=bounds,                  # 0.01 ≤ w_i ≤ 0.40
        constraints=constraints_list    # sum=1, US≤0.50, KR≤0.50, EM≤0.30
    )
    return result.x if result.success else None
```

> **주의**: MVP는 기대수익률(Π)을 입력으로 받지 않으므로, BL 내재수익률 λ와 무관하게 작동. Step 4 최적화와 완전히 독립적으로 실행 가능.

### Sortino-max vs MVP 비교 지표

| 지표 | Sortino-max | MVP | 해석 |
|------|-------------|-----|------|
| 누적 수익률 | 더 높을 가능성 | 낮음 | 수익 추구 vs 분산 최소화 트레이드오프 |
| MDD | - | 더 낮을 가능성 | MVP의 본질적 장점 |
| 소르티노 | 더 높음 (설계상) | 낮음 | Sortino-max 선택 정당성 |
| 유효 자산 수 | - | 더 높을 가능성 | 분산 효과 |
