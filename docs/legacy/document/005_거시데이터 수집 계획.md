## 1. 설계 철학 및 전체 구조

### 1.1 핵심 설계 원칙

거시지표는 포트폴리오 최적화의 **직접 입력값(feature)**이 아닌, 다음 두 가지 역할로 한정합니다.

| 역할 | 설명 | 예시 |
|------|------|------|
| **레짐 식별 (Regime Detection)** | 현재 경제 국면을 분류하여 기대수익률·공분산 추정에 반영 | 긴축 국면 → 채권 ETF 변동성 확대 반영 |
| **수익률 예측 보조 (Return Prediction)** | 팩터 수익률 또는 ETF 수익률의 조건부 기대값 추정 | 금리 상승 국면에서 단기채 ETF 기대수익 하락 조정 |

> **핵심 제약**: 퇴직연금 특성상 **장기 관점(≥1년)** 이 우선입니다. 단기 시장 타이밍에 거시지표를 사용하는 것은 지양합니다.

## 2. 거시지표 선택 프레임워크

### 2.1 선택 기준 (4대 원칙)

수백 개의 거시지표 중 실제로 사용할 지표를 선별하는 기준은 다음과 같습니다.

**① 경제적 유의성 (Economic Relevance)**  
자산가격 결정 이론(APT, ICAPM)에서 이론적 연결고리가 있는 지표만 채택합니다. "데이터가 있으니까 쓴다"는 접근을 지양합니다.

**② 선행성 (Leading Indicator Priority)**  
동행·후행 지표보다 **선행 지표**를 우선합니다. 포트폴리오 리밸런싱은 미래를 향하기 때문입니다.

**③ 고빈도 수집 가능성 (Frequency Compatibility)**  
ETF 일별 데이터와 결합하려면 **월별 이상의 빈도**로 수집 가능한 지표여야 합니다. GDP처럼 분기 발표 지표는 보간 처리가 필요합니다.

**④ 비중복성 (Non-redundancy)**  
다중공선성 분석 후 VIF(분산팽창지수) > 10인 지표는 제거하거나 PCA 합성 지표로 대체합니다.

### 2.2 거시지표 분류 체계

```
거시지표
├── 금리 계열 (Rates)
│   ├── 레벨 지표 (기준금리, 국채금리)
│   └── 스프레드 지표 (신용스프레드, 기간스프레드)
├── 실물경기 계열 (Real Economy)
│   ├── 성장 (GDP, 산업생산)
│   └── 고용 (실업률)
├── 물가 계열 (Inflation)
│   ├── 소비자물가 (CPI)
│   └── 기대인플레이션
├── 유동성 계열 (Liquidity)
│   ├── 통화량 (M2)
│   └── 신용 (대출증가율)
└── 대외 계열 (External)
    ├── 환율 (원/달러)
    └── 교역 (수출입)
```

## 4. 다중공선성 문제와 해결 전략

### 4.1 문제 진단

거시지표 간 다중공선성은 **구조적 문제**입니다. 제거가 목표가 아니라 **적절한 처리**가 목표입니다.

```
기준금리 ──▶ 국고채 3년 ──▶ 국고채 10년
    │              │
    ▼              ▼
  회사채         기간스프레드         ← 1차 파생 지표
    │
    ▼
신용스프레드                          ← 2차 파생 지표
```

> 기준금리, 국고채 3년, 국고채 10년, 회사채 금리는 상관계수 0.9 이상이 일반적입니다.

### 4.2 단계별 다중공선성 처리 전략

#### Step 1: 스프레드 변환 (가장 먼저 적용)

원시 금리 레벨 대신 **스프레드(차이) 지표**를 사용하면 공선성이 크게 감소합니다.

```python
# 레벨 지표 → 스프레드 지표 변환
df['term_spread']   = df['yield_10y'] - df['yield_3y']      # 기간 스프레드
df['credit_spread'] = df['corp_aa']   - df['yield_3y']      # 신용 스프레드
df['real_rate']     = df['yield_3y']  - df['cpi_yoy']       # 실질금리

# 이후 모델에는 원시 레벨 대신 스프레드 활용
```

#### Step 2: VIF(분산팽창지수) 기반 필터링

```python
from statsmodels.stats.outliers_influence import variance_inflation_factor
import pandas as pd

def calculate_vif(df_macro):
    """
    VIF 계산 및 고공선성 지표 식별
    VIF > 10: 심각한 다중공선성 → 제거 또는 PCA 처리
    VIF 5~10: 중간 수준 → 모니터링
    VIF < 5: 허용 범위
    """
    vif_data = pd.DataFrame()
    vif_data["feature"] = df_macro.columns
    vif_data["VIF"] = [
        variance_inflation_factor(df_macro.values, i)
        for i in range(len(df_macro.columns))
    ]
    return vif_data.sort_values("VIF", ascending=False)

# 예상 VIF 결과 (처리 전)
# 기준금리:       VIF ≈ 45  → 처리 필요
# 국고채 3년:     VIF ≈ 38  → 처리 필요
# 국고채 10년:    VIF ≈ 35  → 처리 필요
# 회사채 AA-:     VIF ≈ 40  → 처리 필요
# CPI:            VIF ≈ 12  → 처리 필요
# 기간 스프레드:  VIF ≈  3  → 허용 (스프레드 변환 효과)
# 신용 스프레드:  VIF ≈  4  → 허용
```

#### Step 3: 주성분 분석 (PCA)으로 잠재 팩터 추출

금리 계열처럼 VIF가 매우 높은 그룹은 PCA로 **직교(uncorrelated) 팩터**로 압축합니다.

```python
from sklearn.preprocessing import StandardScaler
from sklearn.decomposition import PCA
import numpy as np

class MacroPCATransformer:
    """
    금리 계열 지표를 PCA로 압축하여 직교 팩터 생성
    경제적 해석:
      PC1 ≈ 금리 레벨 팩터 (전반적 금리 수준)
      PC2 ≈ 기간구조 팩터 (수익률 곡선 기울기)
      PC3 ≈ 곡률 팩터 (수익률 곡선 볼록성)
    """
    def __init__(self, n_components=3, explained_variance_threshold=0.90):
        self.n_components = n_components
        self.threshold = explained_variance_threshold
        self.scaler = StandardScaler()
        self.pca = None

    def fit_transform(self, rate_features: pd.DataFrame):
        scaled = self.scaler.fit_transform(rate_features)
        
        # 분산 설명력 기준으로 컴포넌트 수 자동 결정
        pca_full = PCA()
        pca_full.fit(scaled)
        cumvar = np.cumsum(pca_full.explained_variance_ratio_)
        n_comp = np.argmax(cumvar >= self.threshold) + 1
        
        self.pca = PCA(n_components=n_comp)
        transformed = self.pca.fit_transform(scaled)
        
        cols = [f"rate_pc{i+1}" for i in range(n_comp)]
        return pd.DataFrame(transformed, index=rate_features.index, columns=cols)

# 금리 계열 그룹 PCA 처리
rate_cols = ['base_rate', 'yield_3y', 'yield_10y', 'corp_aa']
macro_pca = MacroPCATransformer(n_components=3)
rate_factors = macro_pca.fit_transform(df_macro[rate_cols])

# 최종 모델 입력 피처 구성
final_macro_features = pd.concat([
    rate_factors,              # PC1, PC2, PC3 (금리 잠재 팩터)
    df_macro[['term_spread',   # 기간 스프레드 (VIF < 5)
              'credit_spread', # 신용 스프레드 (VIF < 5)
              'real_rate',     # 실질금리 (VIF < 5)
              'cpi_core_yoy',  # 근원물가 (VIF < 5 after 변환)
              'm2_growth',     # M2 증가율 (VIF < 5)
              'usdkrw_chg']]   # 환율 변화율 (VIF < 5)
], axis=1)
```

#### Step 4: 정상성(Stationarity) 확보

거시지표는 대부분 **비정상 시계열(non-stationary)**입니다. 레벨이 아닌 **변화율 또는 차분**을 사용합니다.

```python
def make_stationary(df_macro: pd.DataFrame) -> pd.DataFrame:
    """
    지표별 정상화 처리 방법
    """
    stationary = pd.DataFrame(index=df_macro.index)
    
    # 금리: 레벨값 그대로 사용 (이미 % 단위, 경제적 의미 보존)
    stationary['base_rate']     = df_macro['base_rate']
    stationary['term_spread']   = df_macro['term_spread']
    stationary['credit_spread'] = df_macro['credit_spread']
    
    # 물가: 전년동월비 (YoY) 변화율 → 이미 변화율이므로 레벨 사용
    stationary['cpi_yoy']       = df_macro['cpi_yoy']
    
    # 통화량: 전년동월비 증가율 (로그 차분)
    stationary['m2_growth']     = df_macro['m2'].pct_change(12)
    
    # 환율: 전월비 변화율 (로그 차분)
    stationary['usdkrw_chg']    = np.log(df_macro['usdkrw']).diff()
    
    # GDP: 전분기비 성장률 (분기 데이터 월별 보간 후 사용)
    stationary['gdp_growth']    = df_macro['gdp_growth']
    
    return stationary.dropna()
```

## 5. 거시지표 활용 방법론

### 5.1 방법론 1: 거시 레짐 분류 (핵심 방법론)

거시지표를 사용해 현재 경제 국면을 분류하고, **국면별 기대수익률과 공분산**을 조건부로 추정합니다.

#### 레짐 정의 (4분면 모델)

```
         물가 상승
              │
    ④ 스태그플레이션│ ① 과열 (Overheating)
    (금리 상승 필요)│(긴축 단계, 주식 고점 경계)
──────────────────┼──────────────────── 성장
    경기 침체      │                    강세
    ③ 침체/디플레  │ ② 골디락스
    (완화 기대,    │(성장+저물가, 주식 강세)
     채권 강세)    │
              │
         물가 하락
```

#### 레짐 분류기 구현

```python
import pandas as pd
import numpy as np
from sklearn.mixture import GaussianMixture
from hmmlearn import hmm

class MacroRegimeClassifier:
    """
    거시지표 기반 경제 레짐 분류기
    방법: Hidden Markov Model (HMM) + 거시지표 조건부 확률
    """
    
    REGIME_LABELS = {
        0: '침체/디플레',
        1: '골디락스',
        2: '과열',
        3: '스태그플레이션'
    }
    
    def __init__(self, n_regimes=4):
        self.n_regimes = n_regimes
        self.model = hmm.GaussianHMM(
            n_components=n_regimes,
            covariance_type='full',
            n_iter=200,
            random_state=42
        )
    
    def build_regime_features(self, df_macro: pd.DataFrame) -> np.ndarray:
        """
        레짐 분류에 사용할 핵심 지표 선택
        4분면 모델에 맞춰 성장 + 물가 축으로 구성
        """
        features = pd.DataFrame({
            # 성장 축 (Growth Axis)
            'growth': df_macro.get('ipi_yoy', df_macro.get('gdp_growth', 0)),
            # 물가 축 (Inflation Axis)  
            'inflation': df_macro['cpi_yoy'],
            # 금융 환경 (Financial Conditions)
            'credit_spread': df_macro['credit_spread'],
            'term_spread': df_macro['term_spread'],
        })
        return features.values
    
    def fit(self, df_macro: pd.DataFrame):
        features = self.build_regime_features(df_macro)
        self.model.fit(features)
        return self
    
    def predict(self, df_macro: pd.DataFrame) -> pd.Series:
        features = self.build_regime_features(df_macro)
        regimes = self.model.predict(features)
        return pd.Series(regimes, index=df_macro.index).map(self.REGIME_LABELS)
    
    def predict_proba(self, df_macro: pd.DataFrame) -> pd.DataFrame:
        """
        각 레짐에 속할 확률 반환 (소프트 레짐 분류)
        단일 레짐 할당보다 더 robust한 접근
        """
        features = self.build_regime_features(df_macro)
        proba = self.model.predict_proba(features)
        return pd.DataFrame(
            proba, 
            index=df_macro.index,
            columns=list(self.REGIME_LABELS.values())
        )
```

### 5.2 방법론 2: 팩터 수익률 예측 (선택적 적용)

거시지표로 주요 ETF 팩터(모멘텀, 가치, 품질, 저변동성)의 기대수익률을 조건부로 추정합니다.

```python
from sklearn.linear_model import BayesianRidge
from sklearn.pipeline import Pipeline
from sklearn.preprocessing import StandardScaler

class MacroFactorReturnPredictor:
    """
    거시지표 → ETF 기대수익률 예측
    Bayesian Ridge를 사용하여 과적합 방지
    (OLS 대신 Bayesian: 데이터 부족 시 prior가 regularization 역할)
    """
    
    def __init__(self, target_horizon='1M'):
        """
        target_horizon: '1M' (1개월 선행), '3M', '6M', '12M'
        퇴직연금 특성상 6M~12M 예측이 의미 있음
        """
        self.horizon = target_horizon
        self.models = {}  # ETF 카테고리별 모델
    
    def fit(self, X_macro: pd.DataFrame, y_returns: pd.DataFrame):
        """
        X_macro: 거시지표 피처 (정상화 + PCA 처리 완료)
        y_returns: 각 ETF 카테고리별 미래 수익률
        """
        horizon_map = {'1M': 1, '3M': 3, '6M': 6, '12M': 12}
        shift = horizon_map[self.horizon]
        
        # 미래 수익률을 타겟으로 (lookahead bias 주의: 항상 shift 적용)
        y_future = y_returns.shift(-shift).dropna()
        X_aligned = X_macro.loc[y_future.index]
        
        for col in y_future.columns:
            pipe = Pipeline([
                ('scaler', StandardScaler()),
                ('model', BayesianRidge())
            ])
            pipe.fit(X_aligned, y_future[col])
            self.models[col] = pipe
        
        return self
    
    def predict_expected_returns(self, X_macro_current: pd.DataFrame) -> dict:
        """현재 거시지표 기준 기대수익률 예측"""
        return {
            col: model.predict(X_macro_current)[0]
            for col, model in self.models.items()
        }
```

### 5.3 방법론 3: 동적 공분산 추정 (조건부 변동성)

```python
from arch import arch_model

class RegimeConditionalCovariance:
    """
    레짐별 조건부 공분산 행렬 추정
    단순 롤링 공분산보다 현재 국면을 더 잘 반영
    """
    
    def estimate(
        self,
        returns: pd.DataFrame,
        regime_proba: pd.DataFrame,
        lookback: int = 252
    ) -> np.ndarray:
        """
        레짐 확률로 가중된 공분산 행렬 추정
        
        수식:
          Σ = Σ_regime * P(regime_current) + Σ_unconditional * (1 - confidence)
        """
        recent_returns = returns.iloc[-lookback:]
        current_regime_proba = regime_proba.iloc[-1]
        
        # 레짐별 공분산 행렬 추정
        regime_covs = {}
        for regime, prob in current_regime_proba.items():
            # 해당 레짐에서의 과거 수익률 필터링
            regime_mask = regime_proba.idxmax(axis=1) == regime
            regime_returns = recent_returns[regime_mask.loc[recent_returns.index]]
            
            if len(regime_returns) > 20:  # 최소 20개 관측치 필요
                regime_covs[regime] = (regime_returns.cov().values, prob)
        
        # 확률 가중 평균 공분산
        if regime_covs:
            weighted_cov = sum(
                cov * prob for cov, prob in regime_covs.values()
            )
            total_weight = sum(prob for _, prob in regime_covs.values())
            return weighted_cov / total_weight
        else:
            return recent_returns.cov().values
```

## 6. 프론티어 포트폴리오 × 거시지표 통합 설계

### 6.1 거시지표 조건부 효율적 프론티어

```python
import scipy.optimize as opt

class MacroAwareMVOptimizer:
    """
    거시지표를 반영한 평균-분산 최적화
    
    목적함수: maximize Sharpe Ratio
      max  (μ_p - r_f) / σ_p
      s.t. Σ w_i = 1
           w_i ≥ 0  (공매도 불가: 퇴직연금 제약)
           w_i ≤ w_max  (단일 ETF 최대 비중 제한)
    
    μ: 거시지표 조건부 기대수익률 벡터
    Σ: 거시지표 조건부 공분산 행렬
    """
    
    def __init__(
        self,
        risk_free_rate: float = 0.035,  # 기준금리 반영 (ECOS에서 실시간 업데이트)
        max_weight: float = 0.30,        # 단일 ETF 최대 30%
        min_weight: float = 0.01,        # 최소 1% (스몰 웨이트 제거)
        max_etf_count: int = 15          # 최대 15개 ETF (관리 가능성)
    ):
        self.rf = risk_free_rate
        self.max_w = max_weight
        self.min_w = min_weight
        self.max_n = max_etf_count
    
    def optimize(
        self,
        mu: np.ndarray,       # 기대수익률 벡터 (거시 조건부)
        sigma: np.ndarray,    # 공분산 행렬 (레짐 조건부)
        tickers: list
    ) -> dict:
        
        n = len(tickers)
        
        def neg_sharpe(w):
            port_return = w @ mu
            port_vol = np.sqrt(w @ sigma @ w)
            return -(port_return - self.rf) / (port_vol + 1e-8)
        
        constraints = [{'type': 'eq', 'fun': lambda w: w.sum() - 1}]
        bounds = [(self.min_w, self.max_w)] * n
        
        result = opt.minimize(
            neg_sharpe,
            x0=np.ones(n) / n,
            method='SLSQP',
            bounds=bounds,
            constraints=constraints,
            options={'maxiter': 1000, 'ftol': 1e-9}
        )
        
        weights = result.x
        # 최대 ETF 수 제한: 하위 가중치 ETF 제거 후 재정규화
        if n > self.max_n:
            threshold_idx = np.argsort(weights)[:-self.max_n]
            weights[threshold_idx] = 0
            weights /= weights.sum()
        
        port_return = weights @ mu
        port_vol = np.sqrt(weights @ sigma @ weights)
        sharpe = (port_return - self.rf) / port_vol
        
        return {
            'weights': dict(zip(tickers, weights)),
            'expected_return': port_return,
            'volatility': port_vol,
            'sharpe_ratio': sharpe,
            'regime_adjusted': True
        }
    
    def generate_frontier(
        self,
        mu: np.ndarray,
        sigma: np.ndarray,
        tickers: list,
        n_points: int = 100
    ) -> pd.DataFrame:
        """효율적 프론티어 전체 포인트 생성 (시각화용)"""
        target_returns = np.linspace(mu.min(), mu.max(), n_points)
        frontier = []
        
        for target_ret in target_returns:
            constraints = [
                {'type': 'eq', 'fun': lambda w: w.sum() - 1},
                {'type': 'eq', 'fun': lambda w, r=target_ret: w @ mu - r}
            ]
            result = opt.minimize(
                lambda w: w @ sigma @ w,
                x0=np.ones(len(tickers)) / len(tickers),
                method='SLSQP',
                bounds=[(0, self.max_w)] * len(tickers),
                constraints=constraints
            )
            if result.success:
                vol = np.sqrt(result.fun)
                frontier.append({
                    'return': target_ret,
                    'volatility': vol,
                    'sharpe': (target_ret - self.rf) / vol
                })
        
        return pd.DataFrame(frontier)
```

from enum import Enum

class RiskTolerance(Enum):

@dataclass
class InvestorProfile:
    # 기본 정보
    age: int                            # 현재 나이
    retirement_age: int = 65            # 목표 은퇴 나이
    risk_tolerance: RiskTolerance = RiskTolerance.MODERATE

    min_bond_ratio: float = 0.0         # 최소 채권 비중

    def years_to_retirement(self) -> int:

        생애주기 기반 주식 비중 상한
        고전적 규칙: (100 - 나이)% → 퇴직연금 특성상 보수적 적용
        """

        # 위험 성향별 조정

            RiskTolerance.CONSERVATIVE: -0.15,
            RiskTolerance.MODERATE_CONSERVATIVE: -0.08,
            RiskTolerance.MODERATE: 0.0,
            RiskTolerance.MODERATE_AGGRESSIVE: +0.08,
            RiskTolerance.AGGRESSIVE: +0.15,
        }
        return min(max(base + adjustments[self.risk_tolerance], 0.1), 0.9)

### 7.2 개인화 최적화 파이프라인

```python
class PersonalizedPortfolioOptimizer:
    """
    개인 프로파일 + 거시지표 + 프론티어를 결합한
    개인별 최적 포트폴리오 생성기
    """
    
    def __init__(
        self,
        regime_classifier: MacroRegimeClassifier,
        return_predictor: MacroFactorReturnPredictor,
        cov_estimator: RegimeConditionalCovariance,
        mv_optimizer: MacroAwareMVOptimizer
    ):
        self.regime_clf = regime_classifier
        self.ret_pred = return_predictor
        self.cov_est = cov_estimator
        self.mv_opt = mv_optimizer
    
    def optimize(
        self,
        investor: InvestorProfile,
        df_macro: pd.DataFrame,
        etf_returns: pd.DataFrame,
        etf_metadata: pd.DataFrame
    ) -> dict:
        
        # Step 1: 현재 거시 레짐 파악
        regime_proba = self.regime_clf.predict_proba(df_macro)
        current_regime = regime_proba.iloc[-1].idxmax()
        
        # Step 2: 레짐 조건부 기대수익률 추정
        mu = self.ret_pred.predict_expected_returns(df_macro.iloc[[-1]])
        mu_vec = np.array([mu.get(t, 0) for t in etf_returns.columns])
        
        # Step 3: 레짐 조건부 공분산 추정
        sigma = self.cov_est.estimate(etf_returns, regime_proba)
        
        # Step 4: 개인 제약 조건 반영
        #   - 생애주기 주식 비중 상한 적용
        #   - 퇴직연금 투자 가능 종목 필터 (이미 유니버스에 반영)
        equity_cap = investor.lifecycle_equity_cap
        equity_mask = etf_metadata['asset_class'] == '주식'
        
        # 주식 ETF 최대 비중을 lifecycle_equity_cap으로 제한
        bounds = []
        for ticker in etf_returns.columns:
            is_equity = etf_metadata.loc[ticker, 'asset_class'] == '주식'
            max_w = min(0.30, equity_cap) if is_equity else 0.30
            bounds.append((0.0, max_w))
        
        # Step 5: 샤프지수 최적화 실행
        result = self.mv_opt.optimize(
            mu=mu_vec,
            sigma=sigma,
            tickers=etf_returns.columns.tolist()
        )
        
        # Step 6: 결과 패키징
        result.update({
            'investor_profile': {
                'age': investor.age,
                'years_to_retirement': investor.years_to_retirement,
                'risk_tolerance': investor.risk_tolerance.value,
                'equity_cap': equity_cap,
            },
            'macro_context': {
                'current_regime': current_regime,
                'regime_probabilities': regime_proba.iloc[-1].to_dict(),
                'risk_free_rate': self.mv_opt.rf,
            }
        })
        
        return result
```

| 레짐 예측 정확도 | HMM 레짐 분류 정확도 | > 70% |
| VIF 최대값 | 다중공선성 수준 | < 5 |
| 정보 비율 | 벤치마크 대비 초과 수익 안정성 | > 0.3 |

### 8.3 주요 리스크 및 대응

| 리스크 | 설명 | 대응 방안 |
|--------|------|----------|
| 레짐 전환 지연 | HMM이 레짐 전환을 늦게 감지 | 소프트 확률 사용, 리밸런싱 빈도 조정 |
| 기대수익률 추정 오차 | 거시지표 예측력 과신 | Shrinkage 추정 (Black-Litterman) 병행 |
| 데이터 부족 | 스태그플레이션 레짐 관측 희소 | 사전 지식(prior) 강화, 합성 데이터 보강 |
| 과적합 | 거시 피처 수 과다 | VIF 필터 + Bayesian 정규화 철저히 적용 |
| 미래 거시지표 미수집 | 실시간 리밸런싱 시 최신 데이터 필요 | ECOS API 월별 자동 수집 스케줄러 구축 |
