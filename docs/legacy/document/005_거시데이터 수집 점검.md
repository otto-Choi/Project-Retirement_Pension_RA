## 3. 파생 지표 산출 명세

수집한 원자료에서 **다중공선성을 낮추고 경제적 의미를 높이기 위해** 아래 파생 지표를 산출합니다.

### 3.1 금리 파생 지표 (최우선 산출)

| 파생 지표명 | 산출식 | 경제적 의미 | VIF 예상 |
|------------|--------|------------|---------|
| **기간 스프레드** | 국고채(10년) - 국고채(3년) | 경기 선행성 최강. 역전 시 침체 신호 | < 3 |
| **신용 스프레드** | 회사채(AA-) - 국고채(3년) | 크레딧 시장 리스크 온/오프 | < 4 |
| **실질금리** | 국고채(3년) - CPI총지수(YoY) | 실질 자금 조달 비용 | < 4 |
| **단기 스프레드** *(B1 수집 후)* | 기준금리 - CD(91일) | 단기 유동성 긴축도 | < 3 |
| **한미 금리 스프레드** *(C3 수집 후)* | 국고채(3년) - 미국FFR | 자본 유출입 방향성 | < 4 |

### 3.2 물가 파생 지표

| 파생 지표명 | 산출식 | 경제적 의미 |
|------------|--------|------------|
| **CPI 전년동월비 (YoY)** | `CPI_t / CPI_{t-12} - 1` | 인플레이션 레짐 축 입력값 |
| **근원CPI YoY** | `근원CPI_t / 근원CPI_{t-12} - 1` | 구조적 인플레이션 |
| **CPI-근원CPI 갭** | CPI(YoY) - 근원CPI(YoY) | 에너지·식품 가격 충격 분리 |

### 3.3 유동성 파생 지표

| 파생 지표명 | 산출식 | 경제적 의미 |
|------------|--------|------------|
| **M2 증가율 (YoY)** | `log(M2_t) - log(M2_{t-12})` | 유동성 팽창/수축 환경 |
| **M1/M2 비율** | `M1_t / M2_t` | 유동성 선호도. 상승 시 단기 자산 선호 |

### 3.4 실물경기 파생 지표

| 파생 지표명 | 산출식 | 경제적 의미 |
|------------|--------|------------|
| **전산업생산 YoY** | `IPI_t / IPI_{t-12} - 1` | 실물경기 동행 지표 |
| **수출 YoY** *(A3 수집 후)* | `수출금액_t / 수출금액_{t-12} - 1` | 경기 선행성 활용 |

## 4. 수집 우선순위 요약

```
현재 수집 완료 (20개)
├── 금리 4개      → 파생: 기간·신용·실질금리 스프레드 즉시 산출 가능
├── 물가 3개      → CPI YoY 변환 필요 (현재 레벨값)
├── 유동성 2개    → M2 YoY, M1/M2 비율 산출 가능
├── 대외 1개      → 원/달러 변화율 변환 필요
├── 실물경기 8개  → ⚠️ GDP가 연간만 있음. 분기 실질GDP 수집 시급
└── 심리·자산 2개 → CCSI 종합 지수 추가 필요

★★★ 최우선 추가 (5개): A1~A5
  → 실질GDP(분기), 대출금리, 수출YoY, BSI, CCSI
  → 레짐 분류 정확도에 직결

★★☆ 우선 추가 (5개): B1~B5
  → CD금리, 통안채1년, 취업자수, 광공업생산, 아파트지수
  → 모델 피처 품질 향상

★☆☆ 선택 추가 (7개): C1~C7
  → 국고채2년, 경기선행지수, 미국FFR/VIX/CPI, 원/위안, 경상수지
  → 특수 분석 목적 또는 글로벌 레짐 연동 시 활용

추가 후 최종 원자료 수: 최대 32개
파생 지표 포함 후 피처 풀: 약 40개
VIF 필터 + PCA 압축 후 모델 입력: 8~10개 (목표)
```
