### 1. 페르소나 분류 체계 — 논문에서 직접 검증된 3-클러스터

논문은 K-평균 군집분석(유클리드 거리)으로 은퇴자 493명을 **안정추구형 / 위험중립형 / 위험추구형** 3개 클러스터로 분류했고, ANOVA로 통계적 유의성을 검증했습니다. 이 분류 자체를 프로젝트의 페르소나 근거로 직접 인용할 수 있습니다.

논문의 5문항 설문 척도(표 1)가 특히 중요한데, 이걸 그대로 UI 입력 설문으로 가져올 수 있습니다:

| 번호 | 문항 | 측정 방향 |
| --- | --- | --- |
| 1 | 수익성보다 안정성을 고려해 저축/투자 | 안정 선호 |
| 2 | 주식투자보다 은행저축을 주로 한다 | 안정 선호 |
| 3 | 가장 중요한 투자원칙은 '원금보존' | 안정 선호 |
| 4 | 높은 수익이면 일시적 손해도 감수 (역코딩) | 위험 수용 |
| 5 | 조금 위험하더라도 수익 높으면 투자 (역코딩) | 위험 수용 |

총 4점~20점 스케일 → 논문 기준으로 안정추구형은 평균 16.1점, 위험중립형 12.6점, 위험추구형 11.9점이 나왔습니다. 이 컷오프를 점수 기반 자동 분류 로직으로 쓸 수 있습니다.

### 2. 클러스터별 자산배분 논리 — 표 4에서 직접 추출

논문 표 4가 프로젝트의 포트폴리오 제약 조건 설계에 직접 연결됩니다:

**안정추구형 (n=217)**

- 순자산 평균 2억 9,000만원으로 3집단 중 최고
- 금융자산 변화율 -2.8% → 은퇴 후 금융자산을 소비하는 패턴
- 자가 외 부동산 변화율 31.3%로 가장 높음
- 월평균 연금액이 세 집단 중 가장 많음
- **→ 포트폴리오 제약: MDD < 10%, 채권/원리금 비중 하한 설정, 수익보다 원금보존 우선**

**위험중립형 (n=114)**

- 순자산 약 9,800만원으로 3집단 중 최저
- 금융자산 변화율 -7.2%, 부동산 변화율 18.4% 모두 전체 평균 이하
- 은퇴대비를 하지 않은 비율 87.7%로 가장 높음
- 논문이 "가장 관심을 기울여야 할 집단"으로 명시
- **→ 이 집단이 프로젝트의 핵심 타겟: 방치 기회비용 경고 메시지를 가장 강하게 노출해야 하는 페르소나**

**위험추구형 (n=162)**

- 퇴직금액이 세 집단 중 가장 많고 금융자산 보유액이 상대적으로 높음
- 금융자산 변화율 +7.4% (유일하게 증가)
- 그러나 자가 없는 위험추구형은 금융자산·부동산 변화율이 모두 감소
- 논문 결론: "위험 추구 성향이 은퇴 후 자산 증식에 그다지 큰 도움이 되지 않았다"
- **→ 포트폴리오 제약: 자산 규모에 따라 위험 허용 상한을 동적으로 조정. 순자산이 낮은 위험추구형에는 MDD 경고를 함께 출력**

### 3. 자산증가에 영향을 미치는 변수 — 표 6 로지스틱 회귀 결과

표 6이 입력 변수 설계에 핵심적으로 활용됩니다. 위계적 로지스틱 회귀 3단계 결과에서 통계적으로 유의한 변수들:

- **순자산** (Wald=36.365, p<.001): 가장 강한 예측 변수 → UI에서 현재 총자산 입력 필수
- **월수입** (p<.05): 양적 영향 → 월 추가 납입 예정액 입력 추가
- **부양가족수** (p<.001): 음적 영향 → 부양가족 수 입력 추가
- **배우자 유무** (p<.05): 음적 영향 → 기혼/미혼 입력
- **위험중립형** (Exp(B)=2.209): 위험추구형 대비 자산 증가 가능성 1.549배 높음

이 변수들을 입력 필드로 구성하면 "논문 기반 개인화"라는 차별화 포인트를 발표에서 명확히 주장할 수 있습니다.

논문의 5문항을 그대로 가져와 아래처럼 구현할 수 있습니다:

```csharp
def classify_persona(responses: list[int]) -> str:
    """
    responses: 5개 문항 각 1~4점 응답
    문항 4, 5는 역코딩 (5 - score)
    논문 컷오프: 안정추구 ≥ 14.5, 위험중립 11.5~14.4, 위험추구 ≤ 11.4
    """
    scores = list(responses)
    scores[3] = 5 - scores[3]  # 역코딩
    scores[4] = 5 - scores[4]  # 역코딩
    total = sum(scores)
    
    if total >= 15:
        return "안정추구형"
    elif total >= 12:
        return "위험중립형"
    else:
        return "위험추구형"
```

### 5. 포트폴리오 최적화 제약 조건과 논문의 연결
