## 📋 주제별 요약

### 1. 페르소나 데이터셋 활용 방향

**배경 및 문제 인식**
- 기존에 수집한 페르소나 데이터셋(약 700만 건)을 투자 성향 분류에 활용하려는 논의에서 시작.
- 해당 데이터는 개인을 나타내는 자료이지, 투자 목적으로 설계된 자료가 아님. 투자 성향 분류와의 연결 고리 문제가 제기됨.
- 논문 기반으로 보면, 투자 성향 설문은 투자 관련 질문으로 구성되는 반면, 이 데이터에는 그런 항목이 부족함.

**결론**
- 페르소나 텍스트 전체를 모델 입력으로 쓰는 것은 부적절 → **보조적인 고정값 역할**에 한정.
- 핵심 모델에는 직접 연결 변수가 아니므로 포함하지 않는 방향이 노이즈를 줄이는 방법.
- 시간이 남으면 키워드 기반으로 해석 문구(예: "가족 중심 생활 패턴이 확인되어 은퇴 자금 안정성 우선 고려") 삽입은 가능.
- 2만 개 샘플 추출하여 키워드 분석 방식으로 활용 검토.

### 2. 입력 변수 설계 (점수화 모델)

**논문 기반 핵심 입력 변수 (신예운 제안)**
- 순자산, 월 수입, 부양가족 수, 배우자 유무, 위험 유형 → 5개가 핵심 입력 변수.
- 순자산은 데이터 내 직접 값이 없어 임의 설계 필요.

**추가 논의 변수**
- 나이: 가장 중요한 변수. 나이에 따라 안전자산 비중 자동 조정하는 미국 TDF(Target Date Fund) 방식 참조.
  - 예: 20대 → 주식 80%, 채권 20% / 60대 → 주식 40%, 채권 60%
- 직업: 중요 변수로 인정, 단 분류 작업이 복병.
- 패밀리 타입(가족 구성): 포함 결정 (혼자 거주 vs. 배우자와 거주 등).
- 지역: 단독 변수로는 의미 불분명 → **제외** 결정.
- 군 복무 상태: 분포 불균형(비현역 99.5%) → **제외** 결정.
- 65세 이상 / 10대: 퇴직연금 대상 아님 → **드롭** 결정.

**점수화 방식**
- 논문 기반 점수화 후 클러스터링하거나, 클러스터링 없이 단일 점수로 산출 가능.
- 최종 결론: **클러스터링보다 단일 점수화**가 파이프라인상 더 명확함.
- 새로운 소비자가 입력하면 해당 점수 산출 → 위험자산 비중 결정.
- 기초 점수 산출 후 챗봇 응답으로 **가중치 조정** 방식 검토.

### 3. ETF 포트폴리오 구성 (MPT 기반)

**기본 이론: MPT(Modern Portfolio Theory) + 샤프 지수**
- 효율적 프론티어를 구성한 뒤, 무위험 자산(국고채)과 연결하는 CML(자본시장선)에서 최적 포트폴리오 선택.
- 샤프 지수: 위험 대비 수익률 최적화. 기울기가 높을수록 더 좋은 포트폴리오.

**기초 자산군 구성 (논의)**
- 주식형: 코스피, 코스닥 (국내), S&P 500, 나스닥 (미국), 니케이 (일본), 글로벌 ETF 등
- 채권형: 국고채 장기(무위험 자산), 국내 회사채, 종합 채권
- 원자재, 통화 포함 가능
- ETF 선별 기준: 상관계수가 마이너스 1에 가까운 것들로 구성 → 분산 효과 극대화
- 최종 종목 수: 약 **10~20개** 대표 ETF 선별 (총 1,100여 개 → 필터링)
- 필터 기준: 선물 제거, 상장 폐지 ETF 제거, 총 보수 상위 20% 제거, 운용 규모 소규모 제거

**베타(β) 사용 여부**
- 코로나 등 극단적 시장 변동에 강건한 수익률 측정을 위해 **베타 직접 계산** 방식 채택 (증권사 데이터 수령 없이 자체 계산).
- SML(증권시장선) 방식 → 시장 대비 변동성 측정.

**롤링 윈도우**
- 최적 기간(예: 4년)을 롤링 윈도우로 탐색 → 비중의 편차가 최소화되는 기간 선정.
- 데이터 기간: 2020년 1월 ~ 2025년 4월 30일 (코로나 포함), 2026년 추가 수집 검토.

**리밸런싱 주기**
- 매일 → 불가능 수준, 월별 → 잠정 합의. 3개월은 추가 고민 필요.

### 4. 프로젝트 주제 배경 (퇴직연금)

- 국내 퇴직연금 누적 규모 약 400조 원, 향후 1,000조 이상 예상.
- 대다수가 방치 상태 → 개선 여지가 큰 시장.
- 신입사원 입사 시 퇴직연금 운용 방식을 직접 선택해야 하는 구조 확산 중.
- **문제 정의**: 금융 지식이 부족한 사람도 퇴직연금을 효율적으로 투자할 수 있도록 돕는 AI 기반 포트폴리오 추천 시스템.

### 5. 시스템 구성 (파이프라인 및 결과물)

**전체 파이프라인 (최철원 제안 기준)**
1. 페르소나 데이터에서 변수 추출 → 점수화 (위험 허용 수준 도출)
2. ETF 데이터 수집 및 필터링 → 대표 자산군 선정
3. 시점별 최적 포트폴리오 산출 (MPT + 샤프지수)
4. 개인 점수에 따라 포트폴리오 내 안전/위험 자산 비중 결정
5. 최종 추천 포트폴리오 출력
6. (추가) 비중 적용 → 실제 ETF 상품 매칭

**프론트엔드 결과물**
- **대시보드 형태** (정보 입력 후 결과 즉시 확인) 우선 구현.
- 하단에 "질문하기" 버튼으로 챗봇 연결하는 하이브리드 방식이 이상적이지만 시간 고려 필요.
- 시뮬레이터 형식: 직업/나이 등 정보 입력 → 추천 포트폴리오 + 기대 수익 시각화.

**거시 변수 포함 여부**
- GDP, 환율 등 거시 변수는 **제외** (이미 가격에 반영되어 있다는 전제, 금리만 무위험 수익률로 포함).

### 6. 중간 발표 준비

- 중간 발표는 **다음 주** (5월 중순 예정).
- 발표자 랜덤 선정이므로 **모든 팀원이 전체 내용을 숙지** 필요.
- PPT는 글 위주로 간결하게 구성, Claude 활용하여 빠르게 초안 작성.
- 목요일 밤까지 PPT 초안 공유 목표.
- 동규서가 중간 발표 내용 정리 담당.

- 페르소나 데이터를 투자 성향 분류에 바로 활용하는 것의 문제점을 신예운과 동일하게 인식하고 분석 시도.
- 같은 투자 성향이라도 동일한 금융 상품을 추천하는 것이 적절하지 않다는 의견 제시.
- 데이터셋 탐색 및 전처리 보조 역할.
- 페르소나 파트 내 변수 선정 작업 참여.

### 강신영

- 페르소나 데이터에서 700만 건 중 2만 건 샘플 추출하여 키워드 분석 시도.
- 신예운, 오병은과 함께 페르소나 팀으로 활동.
