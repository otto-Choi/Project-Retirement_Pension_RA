- 투자자금
    
    <aside>
    ⭐
    
    투자자금은 단순한 금액이 아니라 개인의 소득, 자산, 현금흐름 대비 얼마나 부담 가능한 투자 여력인지 수치화 하는 파트로 잡아야함 → 세 파트로 나눌 예정 
    
     * 강제적으로 투자해야하는 자금이기 때문에 이를 감안하기 
    
    1. 운용자금 부담도
    
    2. 유동성 안정성 
    
    3. 장기 투자 적합성
    
    3개를 각각 점수화 → 자금 여력 점수  
    
    | 차용 개념 | 활용 방식 | 참고 근거 |
    | --- | --- | --- |
    | 투자자 적합성 원칙 | 나이, 재무상황, 유동성 필요, 투자기간, 위험성향 등을 함께 고려 | FINRA Rule 2111은 고객 투자 프로필에 나이, 재무상황, 유동성 필요, 투자기간, 위험성향 등이 포함된다고 설명함. |
    | 비상자금 기준 | 투자 전 최소 생활 안전판 평가 | CFP는 필수지출의 3~6개월치 비상자금을 확보하는 것이 좋다고 제시함. |
    | 부채상환부담비율, DTI | 월 소득 대비 부채 부담 평가 | CFPB의 Ability-to-Repay/QM 관련 자료에서 43% DTI 기준이 언급되며, 상환능력 평가에서 DTI가 중요한 기준으로 사용됨. |
    | 투자기간과 위험자산 비중 | 은퇴까지 남은 기간이 길수록 위험자산 비중을 높일 수 있음 | Vanguard는 투자기간이 1~3년이면 저위험, 3~10년이면 중간 위험, 10년 이상이면 성장성이 높은 자산도 고려할 수 있다고 설명함. |
    | 퇴직연금 위험자산 한도 | 위험자산 비중 상한선 설정 | DC·IRP 퇴직연금 계좌는 손실 가능성이 큰 상품의 보유 비중을 70%로 제한하는 위험자산 투자한도를 둔다는 설명이 있음. |
    
    근데 의문점: 리밸런싱할때 투자자금을 더 넣어서 추가로 투자하는건 아닌지? 이건 보조조건으로 쓰는건 어떤지?

    1️⃣
    
    운용 자금 부담도 
    
    1.1 개념
    
     : 사용자가 입력한 투자 가능 금액이 총자산 대비 얼마나 큰 비중인지 보는 지표 
    
    (같은 1억이라도 총자산 3억중 1억, 20억중 1억 다름) 
    
    1.2 입력값 
    
    | 입력값 | 설명 |
    | --- | --- |
    | 총자산 | 사용자의 전체 자산 |
    | 운용 대상 금액 | 포트폴리오에 실제 투입할 금액 |
    |  |  |
    
    1.3 계산식 
    
    ```
    운용자금 비율 = 운용 대상 금액 / 총자산
    ```
    
    예시:
    
    ```
    총자산 = 3억 원
    운용 대상 금액 = 1억 원
    
    운용자금 비율 = 1억 / 3억 = 33.3%
    ```
    
    1.4 점수화 
    
    비율이 낮을수록 자금 여력이 높음 
    
    | 운용자금/총자산 비율 | 해석 | 점수 |
    | --- | --- | --- |
    | 0~20% | 부담 낮음 | 10점 |
    | 20~40% | 보통 | 7점 |
    | 40~60% | 부담 높음 | 4점 |
    | 60% 초과 | 과도한 집중 | 1점 |
    
    (*점수는 지금 임의로 정한것) 
    
    </aside>

    2️⃣
    
    유동성 안정성 
    
    개념: 유동성 안전성은 투자 후에도 사용자가 급한 상황에 쓸 수 있는 현금성 자산이 충분히 남는지를 보는 지표
    
    퇴직연금/장기투자 포트폴리오는 단기 현금화가 목적이 아니기 때문에, 투자 후 현금이 거의 남지 않는다면 높은 위험자산 비중을 추천 x 
    
    2.1 입력값 
    
    | 입력값 | 설명 |
    | --- | --- |
    | 현금성 자산 | 예금, 적금, CMA, 파킹통장 등 |
    | 운용 대상 금액 | 장기투자에 투입할 금액 |
    | 월 필수지출 | 선택 입력. 생활비 기준 계산용 |
    - 단 월 필수지출은 필수 입력 x
    - 만약 입력 받는다고 하면  🔽
        
        ```
        비상자금 개월 수 = 투자 후 현금성 자산 / 월 필수지출
        ```
        
        비상자금 개월 수가 높을수록 안ㅇ정적 
        
        예시:
        
        ```
        투자 후 현금성 자산 = 2,000만 원
        월 필수지출 = 300만 원
        
        비상자금 개월 수 = 2,000 / 300 = 약 6.7개월
        ```
        
    
    2.2 투자 후 현금성 자산 
    
    ```
    투자 후 현금성 자산 = 현금성 자산 - 현금에서 투입하는 운용자금
    ```
    
    예시:
    
    ```
    현금성 자산 = 5,000만 원
    이 중 투자에 투입하는 금액 = 3,000만 원
    
    투자 후 현금성 자산 = 2,000만 원
    ```
    
    | 투자 후 현금성 자산 상태 | 점수 |
    | --- | --- |
    | 충분함 | 10점 |
    | 보통 | 7점 |
    | 부족함 | 4점 |
    | 거의 없음 | 1점 |
    
    유동성 안전성이 높으면 단기 변동성을 버틸 가능성이 높다.
    
    반대로 유동성이 낮으면 손실이 났을 때 어쩔 수 없이 매도할 위험이 커진다.
    
    따라서 유동성 안전성은 Risk Score에 중요한 자금 변수로 들어간다.
    
    ```
    유동성 안전성 높음 → Risk Score 상승
    유동성 안전성 낮음 → Risk Score 하락
    ```

    3️⃣
    
    장기투자 적합성  (필요할까??) 
    
    장기투자 적합성은 사용자가 입력한 운용 대상 금액이 **단기적으로 써야 할 돈이 아닌지** 확인하는 지표
     
    
    예를 들어 1년안에 써야할 자금인데 그 돈을 ETF 포트폴리오에 넣는 경우 
    
    → 운용자금이 충분해 보여도 실제로 장기투자에 적합하지 x 
    
    ## 3.2 입력값
    
    | 입력값 | 설명 |
    | --- | --- |
    | 1년 내 사용 예정 자금 | 단기 목적 자금 |
    | 운용 대상 금액 | 장기투자에 넣으려는 금액 |
    | 자금 사용 목적 | 은퇴자산, 주택, 결혼, 교육비 등 |
    
    ---
    
    ## 3.3 계산식
    
    ```
    단기자금 침범 비율 = 1년 내 사용 예정 자금 중 운용자금에 포함된 금액 / 운용 대상 금액
    ```
    
    프로토타입에서는 너무 복잡하게 하지 말고, 질문형으로 처리해도 됨.
    
    ```
    입력한 운용 대상 금액 중 1년 내 사용할 예정인 자금이 포함되어 있나요?
    ```
    
    선택지:
    
    ```
    없음
    일부 포함
    대부분 포함
    ```
    
    ---
    
    ## 3.4 점수화
    
    | 상태 | 해석 | 점수 |
    | --- | --- | --- |
    | 단기 필요자금과 완전히 분리 | 장기투자 적합 | 10점 |
    | 일부 겹침 | 주의 필요 | 5점 |
    | 대부분 단기 필요자금 | 장기투자 부적합 | 1점 |
    
    ---
    
    ## 3.5 Risk Score 반영 해석
    
    장기투자 적합성이 낮으면 위험자산 비중을 높이면 안 된다.
    
    왜냐하면 투자기간이 짧아질수록 시장 변동성을 회복할 시간이 부족하기 때문이야.
    
    ```
    단기 필요자금 없음 → Risk Score 상승
    단기 필요자금 포함 → Risk Score 하락
    ```

    ## 5.1 자금 여력 점수 구조 (가중치 임의 설정한것, 변경예정)
    
    ```
    자금 여력 점수 =
    운용자금 부담도 점수 × 0.4
    + 유동성 안전성 점수 × 0.35
    + 장기투자 적합성 점수 × 0.25
    ```
    
    ---
    
    ## 5.2 가중치 설정 이유
    
    | 항목 | 가중치 | 이유 |
    | --- | --- | --- |
    | 운용자금 부담도 | 40% | 투자금이 총자산 대비 과도한지 판단하는 핵심 지표 |
    | 유동성 안전성 | 35% | 손실 발생 시 강제매도를 피할 수 있는지 판단 |
    | 장기투자 적합성 | 25% | 단기 필요자금 여부를 반영 |
    
    ## 계산 예시
    
    사용자 조건:
    
    ```
    총자산: 3억 원
    운용 대상 금액: 1억 원
    현금성 자산: 5,000만 원
    투자 후 현금성 자산: 2,000만 원
    월 필수지출: 300만 원
    1년 내 사용 예정 자금: 없음
    ```
    
    ## 최종 자금 여력 점수
    
    ```
    자금 여력 점수
    = 7 × 0.4 + 10 × 0.35 + 10 × 0.25
    = 2.8 + 3.5 + 2.5
    = 8.8점
    ```
    
    따라서 이 사용자의 자금 여력 점수는:
    
    ```
    8.8 / 10점
    ```

- 투자자금 수정
    
    🎯 **target: 퇴직연금 적립금을 어떤 위험수준으로 운영할 수 있는가** 
    
    ```
    Part 1. 적립금 규모 기반 손실 감내도
    Part 2. 퇴직연금 기여 안정성
    Part 3. 계좌 내 리밸런싱 여력
    ```
    
    ### part 1. 적립금 규모 기반 손실 감내도
    
    **손실부담이 낮을수록 risk score상승**
    
    ```
    이 사용자가 현재 퇴직연금 적립금에서 어느 정도 평가손실을 감내할 수 있는가?
    예를 들어 10%손실이라는 값도 500만원 안에선 50만원, 1억원안에선 1000만원이 됨 
    -> 체감 손실이 다르다 
    ```
    
    #### 입력값
    
    | 입력값 | 설명 |
    | --- | --- |
    | 현재 퇴직연금 적립금 | 현재 DC/IRP 계좌 평가금액 |
    | 예상 허용 손실률 | 사용자가 감내 가능한 손실률 |
    | 은퇴까지 남은 기간 | 손실 회복 가능 기간 |
    
    #### 계산 지표
    
    ```
    예상 손실금액 = 현재 퇴직연금 적립금 × 예상 MDD
    ```
    
    예시:
    
    ```
    현재 적립금: 1억 원
    추천 포트폴리오 예상 MDD: -15%
    
    예상 손실금액 = 1억 × 15% = 1,500만 원
    ```
    
    사용자에게 이렇게 보여줄 수 있음.
    
    ```
    이 포트폴리오는 과거 변동성 기준 최대 약 1,500만 원 수준의 평가손실 가능성이 있습니다.
    ```
    
    #### 점수화 예시
    
    | 예상 손실금액 / 연간 퇴직연금 기여금 | 해석 | 점수 |
    | --- | --- | --- |
    | 0~1배 | 손실 회복 부담 낮음 | 10점 |
    | 1~2배 | 보통 | 7점 |
    | 2~3배 | 부담 높음 | 4점 |
    | 3배 초과 | 부담 매우 높음 | 1점 |
    
    여기서 연간 퇴직연금 기여금은 대략:
    
    ```
    연간 퇴직연금 기여금 ≈ 연봉 × 1/12
    ```
    
    DC형에서는 사용자가 연간 임금총액의 12분의 1 이상을 정기적으로 부담하는 구조이므로, 이 기준은 제도와 잘 맞는다
    
    ---
    
    ### part2. 퇴직연금 기여 안정성
    
    **기여 안정성이 높을수록 risk score 상승** 
    
    일반 투자계좌처럼 “월 여유 현금흐름”보다 더 중요한 건:
    
    ```
    앞으로 퇴직연금 부담금이 안정적으로 계속 들어올 가능성이 높은가?
    ```
    
    #### 입력값
    
    | 입력값 | 설명 |
    | --- | --- |
    | 연봉 또는 월급 | 연간 퇴직연금 부담금 추정 |
    | 직업 안정성 | 향후 기여 지속 가능성 |
    | 예상 근속 가능성 | 현재 직장에서 퇴직연금이 계속 쌓일 가능성 |
    | 은퇴까지 남은 기간 | 향후 기여 기간 |
    
    ---
    
    #### 계산 지표
    
    ```
    예상 연간 기여금 = 연봉 / 12
    ```
    
    ```
    은퇴 전 예상 추가 기여금 = 예상 연간 기여금 × 은퇴까지 남은 기간
    ```
    
    예시:
    
    ```
    연봉: 6,000만 원
    예상 연간 기여금: 500만 원
    은퇴까지 남은 기간: 25년
    
    예상 추가 기여금 = 500만 원 × 25년 = 1억 2,500만 원
    ```
    
    이 값이 크면 현재 일부 변동성을 감수할 수 있는 여력이 더 커진다.
    
    왜냐하면 앞으로도 적립금이 계속 들어와 평균매입 효과와 회복 기회가 있기 때문
    
    #### 점수화 예시
    
    | 기여 안정성 | 기준 | 점수 |
    | --- | --- | --- |
    | 높음 | 안정적 직업 + 은퇴까지 20년 이상 | 10점 |
    | 보통 | 안정성 보통 또는 은퇴까지 10~20년 | 7점 |
    | 낮음 | 소득 변동 큼 또는 은퇴까지 5~10년 | 4점 |
    | 매우 낮음 | 은퇴 임박 또는 기여 불확실 | 1점 |

    ### **part 3. 계좌 내 리밸런싱 여력**
    
    **개선 여지가 클수록 포트폴리오 조정 폭 확대** 
    
    ## 입력값
    
    | 입력값 | 설명 |
    | --- | --- |
    | 현재 원리금보장형 비중 | 방치 여부 판단 |
    | 현재 위험자산 비중 | 법적 한도 근접 여부 |
    | 현재 안전자산 비중 | 30% 안전자산 유지 여부 |
    | 현재 ETF/펀드 비중 | 이미 운용 중인지 판단 |

    ## 계산 지표 1: 위험자산 추가 여력
    
    ```
    위험자산 추가 여력 = 70% - 현재 위험자산 비중
    ```
    
    예시:
    
    ```
    현재 위험자산 비중: 20%
    위험자산 추가 여력 = 70% - 20% = 50%p
    ```
    
    이 사람은 공격형 포트폴리오로 조정할 여지가 큼.
    
    반대로:
    
    ```
    현재 위험자산 비중: 68%
    위험자산 추가 여력 = 70% - 68% = 2%p
    ```
    
    이 사람은 이미 한도에 가까우므로 추가 위험 확대가 어렵다.

    ## 계산 지표 2: 방치자산 비중
    
    ```
    방치자산 비중 = 원리금보장형 비중
    ```
    
    예시:
    
    ```
    원리금보장형 100%
    → 방치자산 비중 100%
    → 개선 여지 큼
    ```
    
    기획안에서도 원리금보장형 100% 방치 포트폴리오의 기회비용을 계산하는 구조가 핵심이므로, 이 지표는 프로젝트 스토리와도 잘 맞는다.
    
    ---
    
    ## 점수화 예시
    
    | 현재 상태 | 해석 | 점수 |

    | 원리금보장형 70% 이상 | 리밸런싱 개선 여지 큼 | 10점 |
    | 위험자산 30~50% | 균형 조정 여지 있음 | 7점 |
    | 위험자산 50~70% | 한도 근접, 조정 제한 | 4점 |
    | 위험자산 70% 초과 또는 제약 위반 | 조정 필요, 위험 확대 불가 | 1점 |
    
    ## 입력값
    
    | 입력값 | 설명 |
    | --- | --- |
    | 현재 원리금보장형 비중 | 방치 여부 판단 |
    | 현재 위험자산 비중 | 법적 한도 근접 여부 |
    | 현재 안전자산 비중 | 30% 안전자산 유지 여부 |
    | 현재 ETF/펀드 비중 | 이미 운용 중인지 판단 |
