# 전체가이드라인

- 1. 데이터수집
    
    ## A. ETF 가격 데이터
    
    가장 핵심.
    
    | 데이터 | 예시 | 용도 |
    | --- | --- | --- |
    | ETF 일별 종가 | KODEX 200, TIGER 미국S&P500 등 | 수익률 계산 |
    | 거래량 | 일별 거래량 | 너무 안 팔리는 ETF 제외 |
    | 순자산총액 | ETF 규모 | 안정적인 ETF만 남기기 |
    | ETF 분류 | 국내주식, 해외주식, 채권, 리츠 등 | 자산군 구분 |
    
    출처는 KRX 정보데이터시스템이나 pykrx를 쓰면 됨. KRX에는 ETF 전종목 시세, ETF 상세검색, 개별종목 정보 등이 있음.
    
    ## B. 매크로 데이터
    
    ETF 비중을 조정하는 데 씀.
    
    | 데이터 | 출처 | 용도 |
    | --- | --- | --- |
    | 기준금리 | ECOS | 금리 상승/하락 국면 판단 |
    | 국고채 3년/10년 금리 | ECOS | 채권 ETF 비중 조정 |
    | CPI 물가 | ECOS | 실질수익률 계산 |
    | 환율 | ECOS | 해외 ETF 위험 설명 |
    
    ECOS는 한국은행 경제통계시스템이고, Open API로 통계 데이터를 받을 수 있음.
    
    ## C. 퇴직연금 기준 데이터
    
    이건 “방치하면 손해”를 보여주기 위한 데이터.
    
    | 데이터 | 용도 |
    | --- | --- |
    | 원리금보장형 평균 금리 | 현재 방치 포트폴리오 수익률 가정 |
    | 퇴직연금 수익률 통계 | 문제 배경 제시 |
    | DC/IRP 적립금 규모 | 시장성 설명 |
    
    개인 DC/IRP 포트폴리오 데이터는 공개되지 않기 때문에, 무료로 확보 가능한 ETF·ECOS·공공데이터를 조합하는 전략이 제시되어 있음.
    
    ## D. 논문 기반 페르소나 데이터
    
    실제 개인 거래 데이터는 거의 못 구하니까, 논문과 기존 투자성향 분류 기준을 바탕으로 페르소나를 만든다.
    
    예:
    
    | 페르소나 | 특징 |
    | --- | --- |
    | 안정형 | 손실 회피 강함, 채권/현금성 비중 높음 |
    | 중립형 | 주식과 채권 균형 |
    | 공격형 | 장기 수익 추구, 주식 ETF 비중 높음 |
    | 은퇴임박형 | 손실 방어 중요 |
    | 방치형 | 원리금보장형 비중 과다 |
- 2. 데이터 정제 및 전처리
    
    ## Step 1. ETF 후보군 정리
    
    처음부터 ETF 100개 쓰면 너무 복잡함.
    
    처음엔 **15~20개 정도**만 고르는 게 좋음.
    
    예:
    
    | 자산군 | ETF 예시 |
    | --- | --- |
    | 국내주식 | KOSPI200 ETF |
    | 미국주식 | S&P500 ETF, NASDAQ100 ETF |
    | 국내채권 | 국고채 ETF, 종합채권 ETF |
    | 미국채권 | 미국채 ETF |
    | 배당 | 고배당 ETF |
    | 리츠 | 리츠 ETF |
    | 현금성 | 단기채, CD금리 ETF |
    
    ## Step 2. 가격 데이터 정리
    
    필요한 형태:
    
    정리할 것:
    
    - 날짜 형식 통일
    - 결측치 제거
    - 상장일이 너무 짧은 ETF 제외
    - 거래량 너무 적은 ETF 제외
    - 순자산총액 너무 작은 ETF 제외
    
    | date | etf_code | etf_name | close | volume | asset_class |
    | --- | --- | --- | --- | --- | --- |
    
    ## Step 3. 수익률 계산
    
    종가를 그대로 쓰는 게 아니라, 수익률로 바꿈.
    
    예:
    
    > 어제 100원, 오늘 102원이면 수익률 2%
    > 
    
    계산할 지표:
    
    | 지표 | 뜻 |
    | --- | --- |
    | 일간 수익률 | 하루 수익률 |
    | 연환산 수익률 | 1년 기준 기대수익률 |
    | 변동성 | 얼마나 흔들리는지 |
    | 상관계수 | ETF끼리 같이 움직이는지 |
    | 공분산 행렬 | 최적화 계산 재료 |
    | MDD | 최대 손실폭 |
    | 샤프지수 | 위험 대비 수익률 |
    
    ## Step 4. 매크로 데이터 붙이기
    
    ECOS 데이터는 보통 월별/일별이라 ETF 데이터와 날짜를 맞춰야 함.
    
    예:
    
    | date | ETF 수익률 | 기준금리 | 국고채금리 | 환율 | 금리국면 |
    | --- | --- | --- | --- | --- | --- |
    
    금리국면 예:
    
    - 기준금리 최근 3개월 상승 → 금리 상승기
    - 기준금리 최근 3개월 하락 → 금리 하락기
    - 변화 거의 없음 → 중립기
    
- 3. 전체 분석 틀
    
    ### 1단계. 사용자 입력
    
    대시보드에서 사용자가 입력.
    
    필수 입력:
    
    | 입력값 | 예시 |
    | --- | --- |
    | 현재 자산 | 3,000만 원 |
    | 월 납입액 | 50만 원 |
    | 은퇴까지 남은 기간 | 25년 |
    | 투자 성향 | 안정형 / 중립형 / 공격형 |
    | 현재 포트폴리오 | 원리금보장형 80%, ETF 20% |
    
    추가하면 좋은 입력:
    
    | 입력값 | 이유 |
    | --- | --- |
    | 최대 감내 손실률 | “-10% 이상 손실은 싫다” 반영 |
    | 선호 자산 | 미국주식 선호 등 |
    | 투자 경험 | 초보자/경험자 구분 |
    | 리밸런싱 주기 | 6개월/1년 |
    | ESG 선호 여부 | 선택 옵션 |
    
    ## 2단계. 페르소나 매칭
    
    실제 거래 데이터로 클러스터링하지 않고, 논문 기반 규칙으로 분류.
    
    예:
    
    | 조건 | 페르소나 |
    | --- | --- |
    | 은퇴까지 20년 이상 + 손실 감내 높음 | 공격형 |
    | 은퇴까지 10~20년 + 손실 감내 중간 | 중립형 |
    | 은퇴까지 10년 미만 + 손실 감내 낮음 | 안정형 |
    | 원리금보장형 80% 이상 | 방치형 |
    | 주식 ETF 80% 이상 + 은퇴 5년 이내 | 위험과다형 |
    
    ## 3단계. 현재 포트폴리오 진단
    
    현재 상태를 점수화.
    
    보여줄 것:
    
    | 지표 | 의미 |
    | --- | --- |
    | 기대수익률 | 앞으로 얼마나 벌 가능성이 있는지 |
    | 변동성 | 얼마나 흔들리는지 |
    | 샤프지수 | 위험 대비 성과 |
    | MDD | 최악의 손실 가능성 |
    | 방치 위험도 | 원리금보장형 과다 여부 |
    | 은퇴 적합도 | 나이/기간 대비 적절한지 |
    
    ---
    
    ## 4단계. 추천 포트폴리오 생성
    
    MPT 기반으로 ETF 비중 계산.
    
    예:
    
    | 페르소나 | 추천 방향 |
    | --- | --- |
    | 안정형 | 채권/현금성 ETF 중심 |
    | 중립형 | 주식 50, 채권 40, 대체 10 |
    | 공격형 | 주식 ETF 중심 |
    | 은퇴임박형 | 변동성 낮추기 |
    | 방치형 | 원리금보장 일부를 ETF로 전환 |
    
    ---
    
    ## 5단계. 기회비용 계산
    
    사용자에게 가장 강하게 와닿는 부분.
    
    예:
    
    | 구분 | 25년 후 예상 자산 |
    | --- | --- |
    | 현재 유지 | 1.8억 원 |
    | 추천 포트폴리오 적용 | 3.1억 원 |
    | 기회비용 | 1.3억 원 |
    
    문구:
    
    > 현재 포트폴리오를 유지하면 은퇴 시점에 약 1.3억 원의 기회비용이 발생할 수 있습니다.
    > 
    
    ---
    
    ## 6단계. 설명 가능성 XAI
    
    “왜 이 포트폴리오를 추천했는지” 설명.
    
    예:
    
    | 요인 | 추천에 미친 영향 |
    | --- | --- |
    | 은퇴까지 25년 남음 | 주식 ETF 비중 증가 |
    | 공격형 성향 | 위험자산 비중 증가 |
    | 금리 상승기 | 장기채 ETF 비중 감소 |
    | 현재 원리금보장형 과다 | ETF 전환 필요 |
    | 변동성 확대 | 일부 채권/현금성 유지 |
    
- 4. 최종 모델링 + UI/대시보드 구성
    
    ## 모델 구조
    
    최종 모델은 하나의 AI 예측모델이라기보다, **여러 모듈이 합쳐진 추천 시스템**으로 보는 게 맞음.
    
    ## Module 1. 페르소나 분류 모델
    
    입력:
    
    - 나이
    - 은퇴까지 남은 기간
    - 투자성향
    - 감내 손실률
    - 현재 포트폴리오
    
    출력:
    
    - 안정형
    - 중립형
    - 공격형
    - 방치형
    - 위험과다형
    
    처음에는 규칙 기반으로 하고, 나중에 시뮬레이션 데이터로 K-means를 붙일 수 있음.
    
    ---
    
    ## Module 2. 포트폴리오 최적화 모델
    
    입력:
    
    - ETF 기대수익률
    - ETF 변동성
    - ETF 상관관계
    - 사용자 페르소나
    - 금리 국면
    
    출력:
    
    - ETF별 추천 비중
    
    예:
    
    | ETF | 추천 비중 |
    | --- | --- |
    | S&P500 ETF | 35% |
    | KOSPI200 ETF | 15% |
    | 국고채 ETF | 30% |
    | 리츠 ETF | 10% |
    | 단기채 ETF | 10% |
    
    ---
    
    ## Module 3. 기회비용 시뮬레이션
    
    입력:
    
    - 현재 자산
    - 월 납입액
    - 현재 포트폴리오 기대수익률
    - 추천 포트폴리오 기대수익률
    - 은퇴까지 남은 기간
    
    출력:
    
    - 현재 유지 시 미래자산
    - 추천 적용 시 미래자산
    - 차이 금액
    
    ---
    
    ## Module 4. XAI 설명 모델
    
    처음부터 SHAP이 어려우면, 처음엔 규칙 기반 설명으로 시작해도 됨.
    
    예:
    
    > 은퇴까지 남은 기간이 길어 주식 ETF 비중을 높였습니다.
    > 
    > 
    > 최근 금리 상승으로 장기채 ETF 비중은 낮췄습니다.
    > 
    > 현재 원리금보장형 비중이 높아 기대수익률 개선 여지가 큽니다.
    > 
    
    고급 버전에서는 RandomForest로 추천 비중을 예측하게 만들고 SHAP으로 설명.

### 1. 페르소나 분류 체계 — 논문에서 직접 검증된 3-클러스터

논문은 K-평균 군집분석(유클리드 거리)으로 은퇴자 493명을 **안정추구형 / 위험중립형 / 위험추구형** 3개 클러스터로 분류했고, ANOVA로 통계적 유의성을 검증했습니다. 이 분류 자체를 프로젝트의 페르소나 근거로 직접 인용할 수 있습니다.

논문의 5문항 설문 척도(표 1)가 특히 중요한데, 이걸 그대로 UI 입력 설문으로 가져올 수 있습니다:

| 번호 | 문항 | 측정 방향 |
| --- | --- | --- |
| 1 | 수익성보다 안정성을 고려해 저축/투자 | 안정 선호 |
| 2 | 주식투자보다 은행저축을 주로 한다 | 안정 선호 |
| 3 | 가장 중요한 투자원칙은 '원금보존' | 안정 선호 |
| 4 | 높은 수익이면 일시적 손해도 감수 (역코딩) | 위험 수용 |
| 5 | 조금 위험하더라도 수익 높으면 투자 (역코딩) | 위험 수용 |

총 4점~20점 스케일 → 논문 기준으로 안정추구형은 평균 16.1점, 위험중립형 12.6점, 위험추구형 11.9점이 나왔습니다. 이 컷오프를 점수 기반 자동 분류 로직으로 쓸 수 있습니다.

### 2. 클러스터별 자산배분 논리 — 표 4에서 직접 추출

논문 표 4가 프로젝트의 포트폴리오 제약 조건 설계에 직접 연결됩니다:

**안정추구형 (n=217)**

- 순자산 평균 2억 9,000만원으로 3집단 중 최고
- 금융자산 변화율 -2.8% → 은퇴 후 금융자산을 소비하는 패턴
- 자가 외 부동산 변화율 31.3%로 가장 높음
- 월평균 연금액이 세 집단 중 가장 많음
- **→ 포트폴리오 제약: MDD < 10%, 채권/원리금 비중 하한 설정, 수익보다 원금보존 우선**

**위험중립형 (n=114)**

- 순자산 약 9,800만원으로 3집단 중 최저
- 금융자산 변화율 -7.2%, 부동산 변화율 18.4% 모두 전체 평균 이하
- 은퇴대비를 하지 않은 비율 87.7%로 가장 높음
- 논문이 "가장 관심을 기울여야 할 집단"으로 명시
- **→ 이 집단이 프로젝트의 핵심 타겟: 방치 기회비용 경고 메시지를 가장 강하게 노출해야 하는 페르소나**

**위험추구형 (n=162)**

- 퇴직금액이 세 집단 중 가장 많고 금융자산 보유액이 상대적으로 높음
- 금융자산 변화율 +7.4% (유일하게 증가)
- 그러나 자가 없는 위험추구형은 금융자산·부동산 변화율이 모두 감소
- 논문 결론: "위험 추구 성향이 은퇴 후 자산 증식에 그다지 큰 도움이 되지 않았다"
- **→ 포트폴리오 제약: 자산 규모에 따라 위험 허용 상한을 동적으로 조정. 순자산이 낮은 위험추구형에는 MDD 경고를 함께 출력**

### 3. 자산증가에 영향을 미치는 변수 — 표 6 로지스틱 회귀 결과

표 6이 입력 변수 설계에 핵심적으로 활용됩니다. 위계적 로지스틱 회귀 3단계 결과에서 통계적으로 유의한 변수들:

- **순자산** (Wald=36.365, p<.001): 가장 강한 예측 변수 → UI에서 현재 총자산 입력 필수
- **월수입** (p<.05): 양적 영향 → 월 추가 납입 예정액 입력 추가
- **부양가족수** (p<.001): 음적 영향 → 부양가족 수 입력 추가
- **배우자 유무** (p<.05): 음적 영향 → 기혼/미혼 입력
- **위험중립형** (Exp(B)=2.209): 위험추구형 대비 자산 증가 가능성 1.549배 높음

이 변수들을 입력 필드로 구성하면 "논문 기반 개인화"라는 차별화 포인트를 발표에서 명확히 주장할 수 있습니다.

논문의 5문항을 그대로 가져와 아래처럼 구현할 수 있습니다:

```csharp
def classify_persona(responses: list[int]) -> str:
    """
    responses: 5개 문항 각 1~4점 응답
    문항 4, 5는 역코딩 (5 - score)
    논문 컷오프: 안정추구 ≥ 14.5, 위험중립 11.5~14.4, 위험추구 ≤ 11.4
    """
    scores = list(responses)
    scores[3] = 5 - scores[3]  # 역코딩
    scores[4] = 5 - scores[4]  # 역코딩
    total = sum(scores)
    
    if total >= 15:
        return "안정추구형"
    elif total >= 12:
        return "위험중립형"
    else:
        return "위험추구형"
```
