## 0단계: 지표 설정

문장을 바로 `안정형/공격형`으로 분류 x 

대신 문장 하나마다 아래 점수를 만듦

| 지표 | 의미 |  |
| --- | --- | --- |
| Openness | 새로운 경험, 도전, 변화 수용 | 얼마나 성장/확장 가능? |
| Conscientiousness | 계획성, 책임감, 꾸준함 | 얼마나 꾸준히 전략 유지?  |
| Neuroticism(Stability로 변환)  | 불안 민감성, 안정 추구, 손실 회피  | 얼마나 위험/손실 기피? |
- **근거**
    
    심리학의 **BIG FIVE PERSONALITY : 5개의 성격차원 존재**
    
    | 특성 | 의미 |
    | --- | --- |
    | Openness | 새로운 경험/창의성 |
    | Conscientiousness | 성실성/계획성/책임감 |
    | Extraversion | 외향성 |
    | Agreeableness | 협조성 |
    | Neuroticism | 불안/감정변동 |
    
    쓴 이유: 투자 행동 연구랑 연결된 논문이 엄청 많음.
    
    예:
    
    - Openness ↑ → 위험자산 선호 가능성
    - Conscientiousness ↑ → 장기 계획 투자
    - Conscientiousness의 필요성
        
        # Conscientiousness는 생각보다 중요함
        
        근데 이건 조금 달라.
        
        퇴직연금에서 중요한 건:
        
        - 얼마나 공격적으로 투자하냐
        보다
        
        # “시장 하락을 버티고 전략을 유지하느냐”
        
        거든.
        
        ---
        
        예를 들어 현실에서:
        
        - 하락장 오면 손절
        - 리밸런싱 안 함
        - 현금화
        - 감정적으로 ETF 교체
        
        이런 사람이 엄청 많음.
        
        즉 연금 투자 실패는:
        
        - 종목 선정 실패보다
        - 행동 실패가 더 큼.
        
        ---
        
        그래서 성실성/계획성은:
        
        - 정기 투자 유지
        - 장기 전략 유지
        - 감정적 매매 감소
        - 리밸런싱 유지
        
        와 연결 가능성이 있음.
        
        실제 행동재무학에서도:
        
        - self-control
        - disciplined investing
        - impulsiveness
        같은 개념을 중요하게 봄.
    - stability_preference(neuroticism) ↑ → 손실 회피 증가
        - 주의:
            
            투자 프로젝트에서는 “감정 불안정”보다
            
            “손실 민감성/안정 추구” 관점으로 해석하는 게 좋음.
            
    
    > 즉 lifestyle → personality traits → 투자 성향
    >


## 2단계: 라벨 기준표 만들기

# 1. Openness (개방성) 얼마나 성장/ 확장을 원하는지

의미:

- 새로운 경험
- 변화 수용
- 도전 성향
- 창의성/확장 욕구

| 점수 | 기준 |
| --- | --- |
| 1 | 안정적이고 익숙한 삶을 선호하며 새로운 변화나 도전을 크게 원하지 않음 |
| 2 | 변화에 다소 신중하며 현재의 안정성을 우선시함 |
| 3 | 안정과 변화를 균형 있게 추구함 |
| 4 | 새로운 경험과 성장 기회를 적극적으로 받아들이려 함 |
| 5 | 창업, 새로운 분야 도전, 큰 성장과 변화를 강하게 추구함 |

---

# 2. Conscientiousness (성실성/계획성) 얼마나 꾸준히 전략 유지 가능한지

의미:

- 책임감
- 꾸준함
- 자기관리
- 계획성
- 장기 전략 유지 가능성

| 점수 | 기준 |
| --- | --- |
| 1 | 즉흥적이며 장기 계획이나 꾸준한 관리 성향이 거의 드러나지 않음 |
| 2 | 책임감은 있으나 계획적·지속적인 성향은 약함 |
| 3 | 평균적인 수준의 책임감과 자기관리 성향을 보임 |
| 4 | 꾸준한 자기계발과 책임감 있는 태도를 중요하게 여김 |
| 5 | 장기적인 전문성 구축, 계획적 삶, 높은 책임감과 꾸준함을 강하게 추구함 |

---

# 3. stability_preference (안정/손실회피선호) 얼마나 위험/손실 싫어하는지

| 점수 | 기준 |
| --- | --- |
| 1 | 실패·불확실성·변화에 대한 불안이 거의 없으며 위험 감수 성향이 강함 |
| 2 | 변화와 위험에 비교적 유연한 태도를 보임 |
| 3 | 안정과 도전을 모두 고려하는 중립적 성향 |
| 4 | 실패 가능성이나 불확실성을 신중하게 바라보며 안정성을 중요시함 |
| 5 | 평온함·안정·예측 가능한 삶을 강하게 선호하며 손실과 위험을 매우 민감하게 인식함 |

## 3단계: LLM으로 100개만 먼저 점수화

프롬프트는 이런 식으로 가면 돼.

```
다음 lifestyle 문장을 읽고 투자 성향 분석에 사용할 심리 성향 점수를 평가해줘.
- 단어 하나만 보고 판단하지 말고 전체 문맥을 기준으로 판단해라.
- 반드시 lifestyle 전체의 가치관과 태도를 기준으로 평가해라.
- JSON 형식만 출력해라.
-문장에는 직업, 취미, 성격, 내면 상태, 생활 방식이 함께 포함되어 있다.
투자 성향에 직접 연결되는 단어만 보지 말고, 전체 인물 묘사에서 드러나는 삶의 태도와 심리 성향을 기준으로 평가하라.
평가해라. 
중요:
- 모든 점수의 기본값은 3이다.
- 평균적인 직장인·가장·성인은 대부분 3~4 수준이다.
- 4점은 성향이 문장 전체에서 반복적으로 강하게 드러날 때만 부여한다.
- 5점은 매우 드물어야 하며, 매우 높 수준의 성향이 명확할 때만 사용한다.
- 단어 하나가 아니라 삶 전체의 태도와 행동 패턴을 기준으로 평가한다.
평가 지표: openness, 
Openness 기준:
1 = 변화 회피, 익숙한 삶 선호
2 = 현실적·보수적 성향
3 = 평균적 수준의 호기심과 수용성
4 = 창의성·새로운 방식·직무 확장 의지가 뚜렷함
5 = 창업·혁신·예술·비정형 삶 추구가 매우 강함

Conscientiousness 기준:
1 = 무계획적, 충동적, 지속성 부족
2 = 책임감과 자기관리가 약한 편
3 = 일반적인 직장인 수준의 성실함과 책임감
4 = 목표 지향적 자기관리, 꾸준한 전문성 개발, 체계적 생활
5 = 강한 완벽주의, 장기 전략, 매우 높은 자기통제와 실행력

stability_preference 기준:
1 = 위험 감수와 변화 선호가 매우 강함
2 = 변화와 불확실성을 비교적 편하게 수용함
3 = 일반적인 수준의 안정 선호
대부분의 일반적인 중장년 직장인·가장·은퇴 준비형 인물은 stability_preference 3에 해당한다.
4 = 안정적 수입·예측 가능한 삶·건강·정서적 평온을 강하게 중시함
5 = 실패·손실·변화에 대한 불안과 회피 성향이 매우 강함
단순한 가족 책임감, 건강 관리, 안정적 직업 선호만으로는 5점을 주지 마라.

5점은 매우 드물게 사용하라.

문장:
{lifestyle}

출력 형식:
{
  "openness": 1~5,
  "conscientiousness": 1~5,
  "stability_preference": 1~5,
  "reason": "핵심 근거를 한두 문장으로 요약"
}
```

    # 핵심 순서
    
    ## 1단계: 텍스트 준비
    
    예를 들어 컬럼명이 `persona_text`라고 하자.
    
    ```
    importpandasaspd
    
    df=pd.read_csv("persona_data.csv")
    
    text_col="persona_text"
    
    df=df.dropna(subset=[text_col]).reset_index(drop=True)
    
    print(df.shape)
    print(df[text_col].head())
    ```
    
    ---
    
    # 2단계: 문장 embedding 만들기
    
    embedding은 문장을 숫자 벡터로 바꾸는 작업이야.
    
    예를 들어:
    
    ```
    “소박하고 평온한 삶을 지향한다”
    ```
    
    이 문장을 컴퓨터가 이해할 수 있게 숫자 배열로 바꿔주는 거야.
    
    설치:
    
    ```
    !pipinstallsentence-transformers
    ```
    
    코드:
    
    ```
    fromsentence_transformersimportSentenceTransformer
    
    model=SentenceTransformer("jhgan/ko-sroberta-multitask")
    
    texts=df[text_col].tolist()
    
    embeddings=model.encode(
    texts,
    batch_size=64,
    show_progress_bar=True,
    normalize_embeddings=True
    )
    
    print(embeddings.shape)
    ```
    
    예상 출력:
    
    ```
    (100000, 768)
    ```
    
    뜻은:
    
    ```
    10만 개 문장
    각 문장마다 768개 숫자 벡터
    ```
    
    ---
    
    # 3단계: clustering 하기
    
    처음엔 HDBSCAN보다 **KMeans**가 쉬워.
    
    예를 들어 10만 개를 500개 cluster로 묶는다고 하자.
    
    ```
    fromsklearn.clusterimportKMeans
    
    n_clusters=500
    
    kmeans=KMeans(
    n_clusters=n_clusters,
    random_state=42,
    n_init=10
    )
    
    df["cluster"]=kmeans.fit_predict(embeddings)
    
    print(df["cluster"].value_counts().head())
    ```
    
    이제 비슷한 문장끼리 같은 cluster 번호가 붙어.
    
    예:
    
    ```
    cluster 0: 안정적 삶, 정년, 가족 중심
    cluster 1: 창업, 성장, 새로운 도전
    cluster 2: 전문성, 자격증, 실무 숙련
    ...
    ```
    
    ---
    
    # 4단계: cluster 대표 문장 뽑기
    
    각 cluster에서 중심에 가장 가까운 문장을 하나 뽑으면 돼.
    
    ```
    importnumpyasnp
    fromsklearn.metrics.pairwiseimportcosine_similarity
    
    centers=kmeans.cluster_centers_
    
    representatives= []
    
    forcluster_idinrange(n_clusters):
    idx=df[df["cluster"]==cluster_id].index.tolist()
    
    cluster_embeddings=embeddings[idx]
    center=centers[cluster_id].reshape(1,-1)
    
    sims=cosine_similarity(cluster_embeddings,center).flatten()
    best_idx=idx[np.argmax(sims)]
    
    representatives.append({
    "cluster":cluster_id,
    "representative_index":best_idx,
    "representative_text":df.loc[best_idx,text_col],
    "cluster_size":len(idx)
        })
    
    rep_df=pd.DataFrame(representatives)
    
    rep_df.head()
    ```
    
    이렇게 하면 `rep_df`에 cluster별 대표 문장이 생김.
    
    ```
    rep_df.to_csv("cluster_representatives.csv",index=False,encoding="utf-8-sig")
    ```
    
    ---
    
    # 5단계: 대표 문장만 GPT 점수화
    
    이제 10만 개를 GPT에 넣는 게 아니라,
    
    `cluster_representatives.csv`의 **대표 문장 500개만** GPT로 점수화해.
    
    프롬프트는 이런 식.
    
    ```
    다음 인물 설명 문장을 읽고 투자 성향 분석에 사용할 점수를 평가해줘.
    
    중요:
    - 단어 하나만 보지 말고 전체 인물의 삶의 태도와 심리 성향을 기준으로 판단해라.
    - 일반적인 안정 추구는 stability_preference 3~4로 판단하라.
    - 매우 강한 위험 회피와 현상 유지 집착이 있을 때만 5를 부여하라.
    - 새로운 방식 개선, 창작, 창업, 실험, 시스템 구축 의지가 있으면 openness를 중간 이상으로 평가할 수 있다.
    - JSON 형식만 출력해라.
    
    평가 지표:
    1. openness: 변화, 도전, 창의성, 성장, 확장 수용성
    2. conscientiousness: 책임감, 계획성, 꾸준함, 자기관리
    3. stability_preference: 안정, 평온, 손실 회피, 위험 회피 성향
    ```

    # 9단계: persona 규칙 적용
    
    여기서 네가 말한 **6단계 persona 규칙 만들기**를 하면 돼.
    
    중요한 건 원점수로 할지 z-score로 할지 정해야 해.
    
    나는 **z-score 기준 추천**해.
    
    왜냐면 원점수는 전체적으로 안정/성실 쪽으로 높게 나올 가능성이 크거든.
    
    예시:
    
    ```
    defassign_persona(row):
    ifrow["openness_z"]>=0.7androw["stability_preference_z"]<=-0.3:
    return"성장도전형"
    
    elifrow["stability_preference_z"]>=0.5androw["openness_z"]<=-0.3:

    elifrow["openness_z"]>=0.3androw["conscientiousness_z"]>=0.3:

    elifrow["conscientiousness_z"]>=0.5androw["stability_preference_z"]>=0.3:

    df["persona"]=df.apply(assign_persona,axis=1)
    ```

    # 10단계: risk score 만들기
    
    퇴직연금 포트폴리오랑 연결하려면 최종 위험성향 점수가 필요해.
    
    예시:
    
    ```
    df["risk_score"]= (
    0.45*df["openness_z"]
    -0.45*df["stability_preference_z"]
    +0.10*df["conscientiousness_z"]
    )
    ```
    
    해석:
    
    ```
    openness 높음 → 위험자산 선호 증가
    stability_preference 높음 → 위험자산 선호 감소
    conscientiousness 높음 → 장기 전략 유지 가능성 약간 증가
    ```
