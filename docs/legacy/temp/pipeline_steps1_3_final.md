### 대표 ETF 선정 방식 ← **피드백 1 반영**

**변경 전**: AUM 최대값으로 단순 정렬 → 총보수·거래대금 무시  
**변경 후**: 2단계 선정 프로세스

#### 1단계 — 정성적 사전 필터 (hard rule)

1. **순수 지수 추종(plain) 우선**: 커버드콜·스트립·만기형 등 파생 구조 상품 제외
2. **비환헤지(unhedged) 우선**: 환헤지 버전이 별도로 있으면 비환헤지 선택

> *근거*: ETF가 기초자산의 수익률을 그대로 반영해야 하방공분산 행렬이 의미를 가짐. 파생 구조나 환헤지가 섞이면 기초자산 간 상관관계가 왜곡됨.

#### 2단계 — 정량적 가중평균 순위

사전 필터를 통과한 ETF들 안에서:

```
가중 점수 = 총보수 순위 × 0.5 + 거래대금 순위 × 0.3 + AUM 순위 × 0.2
→ 가중 점수가 가장 낮은(=1위에 가장 가까운) ETF 선정
```

| 항목 | 가중치 | 근거 |
|------|--------|------|
| 총보수 | **50%** | 장기 복리 효과에서 비용이 가장 큰 변수. 0.1%p 차이가 10년 누적 수익률에 직접 반영 |
| 일평균 거래대금 | 30% | 분기 리밸런싱 시 슬리피지 결정. 거래대금이 낮으면 실제 체결가가 NAV에서 이탈 |
| AUM | 20% | 청산·괴리율 리스크의 보조 지표. 총보수·거래대금 이후 tiebreaker 역할 |

#### 3단계 — 연도별 × 슬롯별 독립 실행

- **생존편향 차단**: 현재 가장 좋은 ETF를 과거에 소급 적용하지 않음
- 2015년 연도말 기준으로 그 시점에 존재하는 ETF만 평가 → 2016년 1년 적용
- 동일 로직을 2015~2024년 각 연도말에 독립 반복

```python
def select_best_etf(sub_df):
    pool = sub_df[sub_df['is_plain']] or sub_df  # plain 우선
    pool = pool[~pool['is_hedged']] or pool       # unhedged 우선
    pool['r_expense'] = pool['총보수'].rank(ascending=True,  method='min')
    pool['r_value']   = pool['avg_daily_value'].rank(ascending=False, method='min')
    pool['r_aum']     = pool['aum_approx'].rank(ascending=False, method='min')
    pool['w_score']   = pool['r_expense'] * 0.5 + pool['r_value'] * 0.3 + pool['r_aum'] * 0.2
    return pool.loc[pool['w_score'].idxmin()]
```

**채권 수익률 → 가격 수익률 변환 공식**

```python
def yield_to_ret(yield_pct, modified_duration):
    y = yield_pct / 100
    carry   = y / 252          # 매일 적립되는 이자 수익
    delta_y = y.diff()         # 전일 대비 금리 변화
    return (carry - modified_duration * delta_y).dropna()
```

> `daily_ret ≈ YTM/252 − MD × Δy`  
> 채권 가격은 금리와 역방향이므로 금리 상승(Δy > 0) 시 가격 하락. Modified Duration은 금리 변화에 대한 가격 민감도.

### 3-2. MAR(최소 수용 수익률) 시계열 구성 ← **피드백 4 반영**

**변경 이유**: MAR이 고정(2.5%)이면 금리 상승기(2022~)에는 MAR이 실제보다 낮게 설정되어 소르티노 비율이 과대평가됨. 반대로 초저금리 시기(2020~2021)에는 과소평가. 하방공분산 Σ_down 자체가 `min(r − MAR, 0)²`의 함수이므로 MAR이 달라지면 추정 전체가 달라짐.

**데이터 출처**: ECOS 121Y002/BEABAA2111 (예금은행 정기예금 6개월미만 수신금리, 월별)

| 통계 | 값 |
|------|-----|
| 수집 기간 | 2000-01-01 ~ 2025-04-01 |
| 데이터 수 | 304개월 |
| 최솟값 | 0.62% (2021년 초저금리 시기) |
| 최댓값 | 6.55% (2000년대 초) |
| **평균** | **3.00%** |

**일별 적용 방식**: 월별 MAR → `resample('D').ffill()` → 거래일 index로 `reindex` → `ffill/bfill`  
→ 분기 윈도우 평균값을 해당 리밸런싱 구간의 MAR scalar로 사용

### 3-3. Walk-forward 설계 ← **피드백 3·5 반영**

**리밸런싱 주기**: 월별(21거래일) → **분기(63거래일)** 변경  
*근거*: 실전 운용 주기가 분기이므로 탐색 구간도 분기로 일치시켜야 윈도우 선택 근거가 유효. 월별 기준으로 검증하면 실전보다 3배 자주 리밸런싱하는 시나리오를 기준으로 윈도우를 고르는 모순이 발생.

**Walk-forward 구조**

```
전체 기간: 2000-01-03 ~ 2025-04-30 (6,628거래일)

for 각 리밸런싱 시점 t (분기 단위):
    추정(in-sample) 구간 = [t - W, t)     ← 윈도우 W = 252/504/756/1260일
    검증(out-of-sample) 구간 = [t, t+63)  ← 다음 분기

    추정 구간에서:
      1. 결측 30% 이상 슬롯 제외
      2. 유효 슬롯이 3개 미만이면 건너뜀
      3. 하방공분산 Σ_down 산출 (MAR = 추정 구간 평균 MAR)
      4. BL 내재수익률 Π = λ × Σ_down × w_mkt  (w_mkt = 균등, λ=2.5)
      5. SLSQP 최적화 → w_opt (제약: 각 슬롯 1%~40%, 합=100%)

    검증 구간에서:
      6. 실제 수익률로 누적 수익 계산 (cum_r)
      7. OOS 소르티노 = (cum_r − MAR_분기) / sqrt(하방분산 × 63)
      8. 예측 오차 = |pred_down_risk − real_down_risk|
```

### 3-4. 4가지 평가 기준 ← **피드백 3 반영**

**변경 이유**: OOS Sortino 평균만으로 선택하면 특정 구간(예: 2020 코로나 급락 직후 반등기)에서 운 좋게 높은 소르티노를 기록한 윈도우가 유리해질 수 있음. 4가지 기준을 동시에 보면 과적합·이상치 왜곡을 더 잘 걸러낼 수 있음.

| 기호 | 기준 | 목표 방향 | 계산 방식 |
|------|------|----------|---------|
| ① | 평균 예측 오차 (MAE) | **최소화** | `mean(|pred_down_risk − real_down_risk|)` × 100 (%) |
| ② | 실현 소르티노 평균 | **최대화** | `mean(OOS_sortino)` |
| ③ | 소르티노 비율 σ | **최소화** | `std(OOS_sortino)` — 기간별 성과 일관성 |
| ④ | 이상치 민감도 | **최소화** | `|mean_sortino − sortino_이상치제외|` — 이상치 영향력 |

> **③ 기준 중요 주의**: 소르티노 비율 σ는 *예측 오차의 σ*가 아니라 *소르티노 비율 시계열의 σ*임. 소르티노 σ가 낮을수록 윈도우가 특정 국면(금융위기, 급등장 등)에 의존하지 않고 일관된 성과를 낸다는 의미.

#### 가중치 설정 근거

| 가중치 | 기준 | 근거 |
|--------|------|------|
| **35%** | ① 평균 예측 오차 | 하방공분산 Σ_down을 추정해 Π를 산출하는 이 파이프라인에서, 추정 정확도는 최적화 품질의 직접 입력값. MAE가 클수록 포트폴리오 비중이 실제 위험에서 어긋남. 가장 높은 가중치를 부여한 이유 |
| **30%** | ② 실현 소르티노 | 최종 목표인 "투자자가 실제로 경험한 하방대비 초과성과"를 직접 측정. 두 번째로 높게 배정 |
| **25%** | ③ 소르티노 σ (일관성) | 윈도우가 특정 시장 국면에 과적합됐는지 검증. 낮을수록 범용 사용 가능한 안정적 파라미터임을 의미. 세 번째 배정 |
| **10%** | ④ 이상치 민감도 | ③의 일관성 기준과 목적이 유사하지만, 극단 분기(이상치)에만 한정. 보완 지표로 낮은 가중치 배정 |

#### 종합 점수 산식

```python
# 각 지표를 0~1로 정규화 후 방향 반전
sc_mae     = 1 - normalize(MAE)           # MAE: 낮을수록 좋으므로 역방향
sc_sortino = normalize(mean_sortino)       # 소르티노: 높을수록 좋음
sc_consist = 1 - normalize(sortino_std)   # σ: 낮을수록 좋으므로 역방향
sc_outlier = 1 - normalize(sensitivity)   # 민감도: 낮을수록 좋으므로 역방향

종합_점수 = sc_mae*0.35 + sc_sortino*0.30 + sc_consist*0.25 + sc_outlier*0.10
```

## Step 4 진입 준비

### Step 4에서 할 일
1. `year_end_best.csv` + `slot_returns.parquet` → 연도말 선정 ETF의 다음 해 수익률 시계열 구성
2. **5년 윈도우** 기준으로 리밸런싱 시점마다 하방공분산 Σ_down 산출
3. BL 내재수익률 Π = λ × Σ_down × w_mkt 계산 (w_mkt = 연도별 AUM 비중)
4. `mar_series.parquet` → 리밸런싱 시점별 MAR 적용
5. SLSQP로 최적 포트폴리오 비중 w_opt 산출 → 실전 포트폴리오 구성

### 핵심 수식 (Step 4 참조용)

```python
# 하방공분산 (Estrada 2007)
D = np.minimum(R - mar_daily, 0.0)          # R: T×N 행렬, mar_daily: 일별 MAR scalar
Sigma_down = (D.T @ D) / len(D)            # N×N 하방공분산 행렬

# BL 내재수익률
Pi = lambda_ * Sigma_down @ w_mkt          # λ=2.5, w_mkt = AUM 기반 시장비중

# 소르티노 최대화 (SLSQP)
maximize (w @ Pi * 63 - MAR_q) / sqrt(w @ Sigma_down @ w * 63)
subject to: sum(w) = 1, 0.01 ≤ w_i ≤ 0.40
```

### Step 3 → Step 4 가장 중요한 변화

롤링 윈도우 탐색(Step 3)은 **기초자산 지수 데이터**로 진행했지만,  
Step 4부터는 **실제 ETF 수익률**로 전환한다.

- Step 3의 역할: "몇 년치 데이터를 봐야 하는가" 결정 → **5년** 확정
- Step 4의 역할: 실제 투자 가능한 ETF로 포트폴리오 비중 산출

이 구분이 중요한 이유: ETF 수익률은 2015년 이전 데이터가 없어 윈도우 탐색에 부적합하지만, 실제 포트폴리오 구성에는 ETF 데이터를 써야 실제 보수·추적 오차·거래비용이 반영됨.
