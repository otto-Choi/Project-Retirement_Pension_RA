# Step 3 — 기초자산 지수 수집 & 최적 롤링 윈도우 탐색

## 목적
포트폴리오 최적화에 사용할 **추정 기간(윈도우)**이 몇 년이어야 하는가를 결정한다.  
ETF 데이터(상장 2~8년)가 아닌 기초자산 지수(2000년~, 최대 25년)를 사용해 신뢰도를 확보한다.

## 핵심 설계

### 데이터 소스 (13슬롯)
| 슬롯 | 출처 | 변환 |
|------|------|------|
| 코스피·코스닥 | yfinance ^KS11 / ^KQ11 | pct_change() |
| SP500·나스닥·인도·중국 | yfinance ^GSPC / ^NDX / ^NSEI / ^HSI | pct_change() |
| 금 | yfinance GC=F | pct_change() |
| 미국국채 | yfinance ^IRX | annualYTM/100/252 |
| 국내채권 3종 | ECOS 817Y002 (국고채3·30년, 회사채AA-) | yield→price (MD 기반) |
| 무위험(현금성) | ECOS 817Y002 CD91일 | annualYield/100/252 |
| MAR | ECOS 121Y002/BEABAA2111 (정기예금 6개월미만) | 월별 → 일별 ffill |

### 채권 수익률 변환
```
daily_ret ≈ YTM/252 − Modified_Duration × Δy
```

### Walk-forward 구조
- 추정 구간: [t − W, t) — 1·2·3·5년 4가지 윈도우 비교
- 검증 구간: [t, t+63) — 분기(63거래일) OOS 평가
- MAR: 각 구간별 평균 실제 정기예금 금리 적용

### 4가지 평가 기준 및 가중치
| 기준 | 방향 | 가중치 | 근거 |
|------|------|--------|------|
| ① 평균 예측 오차 (MAE) | 최소화 | 35% | Σ_down 추정 정확도 = Π 산출의 직접 입력값 |
| ② 실현 소르티노 평균 | 최대화 | 30% | 실제 투자 성과 직접 측정 |
| ③ 소르티노 비율 σ | 최소화 | 25% | 국면 의존성·과적합 검증 |
| ④ 이상치 민감도 | 최소화 | 10% | ③의 보완 지표 |
