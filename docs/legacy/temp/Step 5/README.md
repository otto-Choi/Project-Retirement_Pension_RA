# Step 5 — 지역별 집중도 제약 + 비제약 vs 제약 비교

## 목적
Step 4의 비제약 포트폴리오에서 발견된 **US 주식 80% 집중 문제**를 해결한다.  
지역별 합계 상한(US ≤ 50%, KR ≤ 50%)을 추가하고,  
**수익 vs 분산** 트레이드오프를 정량 비교해 최종 포트폴리오를 확정한다.

## 추가된 제약 조건

```
기존 (Step 4):  0.01 ≤ w_i ≤ 0.40,  sum(w) = 1
신규 (Step 5):  + Σ(US 주식) ≤ 0.50   [SP500 + 나스닥]
               + Σ(KR 주식) ≤ 0.50   [코스피 + 코스닥]
```

> **실현가능성 체크**: 비해당 슬롯 최대 비중 합 < 50%이면 제약 생략  
> (슬롯 수 적은 2016~2017년에는 KR 제약이 W_MAX=40%와 충돌해 미적용)

## 해석 및 결론

### 제약의 비용
누적 수익률 -25.7%p는 주로 **2021·2023 US 강세기**에 US 비중을 50%로 제한한 결과.  
이는 모델이 과거 US 수익률을 미래에 외삽(extrapolation)하는 경향을 억제한 것.

### 제약의 효과
- **MDD -24.4% vs -34.8%**: 최악의 낙폭을 10.5%p 줄임
- **소르티노 σ 1.659 vs 2.173**: 성과 일관성 향상 (특정 국면 의존도 감소)
- **MAR 초과 빈도 동일 (60.5%)**: 제약이 수익 창출 능력을 해치지 않음
- **2025 관세 충격**: 소르티노 -0.58 vs -1.08 — 방어력 개선 확인

### 최종 선택: **지역제약 포트폴리오 (Step 5)**
실전 투자자 관점에서 MDD 개선(+10.5%p)이 수익 포기(-25.7%p)보다 중요.  
Step 6부터는 이 제약 포트폴리오를 기반으로 무위험자산 비중 배분 진행.
