## Step 4 — 내재수익률 & 하방위험 산출 + 분기별 최적 포트폴리오

> **스크립트**: `Step 4/06_step4_portfolio.py`

### 목적

Step 3에서 확정한 파라미터(5년 윈도우, 분기 리밸런싱, 시변 MAR)와 Step 2에서 선정한 연도별 ETF(`year_end_best.csv`)를 결합해, **2016~2025 분기별 최적 포트폴리오 비중**을 Walk-forward로 산출한다.

### 핵심 설계

#### 추정 vs OOS 분리 원칙

| 구분 | 사용 데이터 | 이유 |
|------|-----------|------|
| 추정 (Σ_down · Π 산출) | `index_returns.parquet` (기초자산 지수, 25년) | Step 3 윈도우 교정과 일관성 유지 |
| OOS 성과 평가 | `slot_returns.parquet` (실제 ETF 수익률) | 실제 보수·추적오차·거래비용 반영 |

#### 핵심 수식

```python
# 하방공분산 (Estrada 2007)
D = np.minimum(r - MAR_daily, 0.0)          # r: T×N, MAR_daily: 일별 scalar
Sigma_down = (D.T @ D) / len(D)             # N×N 하방공분산 행렬

# BL 내재수익률
Pi = lambda_ * Sigma_down @ w_mkt           # λ=2.5, w_mkt = 전년도 AUM 비중

# 소르티노 최대화 (SLSQP)
maximize  (w @ Pi * 63 - MAR_q) / sqrt(w @ Sigma_down @ w * 63)
subject to: sum(w) = 1,  0.01 ≤ w_i ≤ 0.40
```

#### 슬롯 결정 원칙

- **생존편향 차단**: `year_end_best[전년도]` 기준 — 현재 시점 ETF를 과거에 소급 적용하지 않음
- 추정 구간 결측 < 30% 슬롯만 사용
- OOS 구간 ETF 데이터 ≥ 44거래일(63×70%) 슬롯만 포함

## Step 5 — 지역별 집중도 제약 + 비제약 vs 제약 비교

> **스크립트**: `Step 5/07_step5_constrained.py`

### 목적

Step 4의 비제약 포트폴리오에서 발견된 US 주식 80% 집중 문제를 해결한다.  
지역별 합계 상한을 추가하고, 수익 vs 분산의 트레이드오프를 정량 비교해 최종 포트폴리오를 확정한다.

### 추가된 제약 조건

```
기존 (Step 4):  0.01 ≤ w_i ≤ 0.40,  sum(w) = 1

신규 (Step 5):  + Σ(US 주식) ≤ 0.50   [SP500 + 나스닥]
               + Σ(KR 주식) ≤ 0.50   [코스피 + 코스닥]
```

> **실현가능성 체크**: 비해당 슬롯의 최대 비중 합 < 50%이면 충돌 방지를 위해 해당 지역 제약 생략  
> (슬롯이 3개뿐인 2016~2017년에는 KR 제약 미적용)

#### 유효 자산 수 (분산 지표)

```python
eff_n = 1 / HHI = 1 / sum(w_i^2)
# 높을수록 비중이 고르게 분산됨을 의미
```

### 해석 및 결론

#### 제약의 비용

누적 수익률 -25.7%p는 주로 **2021·2023 US 강세기**에 US 비중을 50%로 제한한 결과.  
이는 모델이 과거 US 수익률을 미래에 외삽(extrapolation)하는 경향을 억제한 것으로, 장기 관점에서 건전한 제약이다.

#### 제약의 효과

- **MDD -24.4% vs -34.8%**: 최악의 낙폭을 10.5%p 줄임 — 투자자 실제 경험 리스크 대폭 감소
- **소르티노 σ 1.659 vs 2.173**: 성과 일관성 향상 — 특정 국면(US 강세) 의존도 감소
- **소르티노 > 0 비율 동일 (60.5%)**: 제약이 수익 창출 능력 자체를 해치지 않음
- **2025 관세 충격**: 소르티노 -0.58 vs -1.08 — 관세 리스크 방어력 개선 확인

#### ★ 최종 선택: 지역제약 포트폴리오 (Step 5)

실전 투자자 관점에서 **MDD 개선(+10.5%p)이 수익 포기(-25.7%p)보다 중요**.  
퇴직연금 맥락에서 원금 손실 최소화는 수익 극대화와 동등하거나 더 높은 우선순위를 갖는다.  
Step 6부터는 이 제약 포트폴리오를 기반으로 무위험자산 비중 배분을 진행한다.

## Step 6 진입 준비

### Step 6에서 할 일

1. `portfolio_weights_constrained.parquet` + `portfolio_performance_constrained.parquet` 로드
2. 분기별 리스크자산 포트폴리오 기대수익률(μ_p)·하방위험(σ_down_p) 산출
3. **무위험자산(현금성 ETF)** 비중 배분: CAL(Capital Allocation Line) 상에서 투자자 위험회피 수준에 따른 최적 배분점 결정
4. 나이(은퇴까지 남은 기간) 기반 글라이드패스 제약 적용
5. 최종 전체 포트폴리오 = 리스크자산 포트폴리오 × (1 - μ_f 비중) + 무위험자산 × μ_f 비중

### 핵심 입력값 (Step 5 → Step 6)

```python
# 리스크자산 포트폴리오 (분기별)
w_risky  = portfolio_weights_constrained.parquet   # 13개 슬롯 비중

# CAL 설계 참조 수식
```
