## 핵심 설계

### 추정 vs OOS 분리
| 구분 | 데이터 | 이유 |
|------|--------|------|
| 추정 (Σ_down, Π 산출) | `index_returns.parquet` (지수, 25년) | Step 3 윈도우 교정과 일관성 유지 |
| OOS 성과 평가 | `slot_returns.parquet` (실제 ETF) | 실제 비용·추적오차 반영 |

### 핵심 수식
```
# 하방공분산 (Estrada 2007)
D = min(r − MAR_daily, 0)
Σ_down = (D.T @ D) / T

# BL 내재수익률
Π = λ × Σ_down × w_mkt        (λ=2.5, w_mkt = 전년도 AUM 비중)

# 소르티노 최대화 (SLSQP)
max  (w @ Π × 63 − MAR_q) / sqrt(w @ Σ_down @ w × 63)
s.t. sum(w)=1,  0.01 ≤ w_i ≤ 0.40
```

### 슬롯 결정 원칙
- **year_end_best[전년도]** 기준 — 생존편향 차단
- 추정 구간 결측 < 30% 슬롯만 사용
- OOS 구간 ETF 데이터 ≥ 44거래일(63×70%) 슬롯만 포함

### 주요 이벤트
- **2019-12-17 분기 -22.7%**: OOS 기간이 COVID 폭락(2020 Feb~Mar)과 겹침
- **2020-03-16 분기 +23.4%**: COVID 저점 직후 반등 구간 포착
- **2025 Q1 -10.7%**: 미국 관세 충격 (SP500+NASDAQ = 포트의 80%)

### 발견된 이슈 → Step 5로 이관
2023년 이후 SP500(40%) + 나스닥(40%) = **US 주식 80%** 집중  
→ 두 슬롯 모두 개별 상한(40%)을 지키지만 동일 리스크 팩터에 과집중  
→ Step 5에서 지역별 합계 상한(US ≤ 50%, KR ≤ 50%) 추가
